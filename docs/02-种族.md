# 02 · 种族

> 《定线人》设定集 第二册
> 九个可扮演种族。**硬规则：六项属性 A=3 / B=2 / C=1 / D=0，每族总分恒为 11；每族恰好一 A 一 D；装备槽基准 10，各族差异不超过 2。**
> **种族差异不靠数值，靠身体——每个种族的身体能做一件别的种族做不了的事，也有一件永远做不了的事。**

---

## 一、总则

### 1.1 属性

| 属性 | 管什么 |

| 魅力 | 交易、说服、伙伴忠诚 |

### 1.2 装备槽基准（10 槽）

`头部 / 躯干 / 护臂左 / 护臂右 / 护腿 / 鞋靴 / 背部 / 饰品×2`

主手、副手、坐骑不计入。各族槽位差异写在种族条目里，**差异是身体决定的，不是数值奖励**。

## 二、九族详述

### 洛文人

**洛恩王国的主体民族，中央河谷平原的农民。**

**外形**：普通人类的样子。肤色麦褐，个子中等。城市洛文人穿呢子外套戴圆帽，乡下人穿麻衣，两边互相觉得对方土。

**生理**：没有特殊之处——这不是缺点，是**基准**。所有种族的属性表都以洛文人为参照。

**社会**：河谷的村子围着祠堂和磨坊，城市的洛文人进厂当工人。他们守规矩、信王室、也爱抱怨税。王国军里七成是洛文人。

**习俗**：春祭拜长河，秋祭拜谷仓。婚丧都要请一个望纱教司仪，但平时不进庙。

> 「急什么？还没开河呢。」——洛文人一切事情的答案

**属性**：体魄 C · 灵巧 C · 心智 C · 感知 C · 魅力 B · 意志 B

**特殊能力**：
- 被动 **本地人**：任何城镇的物价 -10%（王国全境通行）
- 主动 **呼救**：城内战斗时，卫兵响应速度快一倍
- 出身 **村产**：开局多一块家里给的田契（可继承、可抵押）

**装备槽**：基准 10 槽

**玩法定位**：新手友好的全能型。没有长板也没有短板，适合第一次玩。

---

### 诺尔人

**北方高地的矿工民族，辉石主产区的主人。**

**外形**：矮壮，肩宽，胳膊比腿粗。手指粗得像短棍，但能捏住米粒。肤色浅，因为矿里不见天日。

**生理**：肺活量极大，能在粉尘里干一整天不咳。暗视——矿井里习惯了，昏暗处视力比常人好。

**社会**：高地城市以矿盟为政治实体。诺尔人社会崇拜"手艺"：一个人被人尊敬的程度，取决于他会做多少种东西。矿工兄弟会是实际上的工人政府。

**习俗**：下井前互相敲三下头盔（"活着上来"）。结婚的聘礼是一把自己打的工具，不是钱。

> 「石头不会骗人。人会。」——诺尔人的处世观

**属性**：体魄 A · 灵巧 C · 心智 D · 感知 B · 魅力 C · 意志 C

**特殊能力**：
- 被动 **铁肺**：粉尘、毒雾环境无惩罚；昏暗视野正常
- 主动 **力士**：搬运、撬动、开锁类检定，一次成功（每日一次）
- 出身 **矿籍**：北境矿盟城市的商店对你是"自己人价"

**装备槽**：基准 10 槽，但天然**无法使用戒指类饰品**（手指太粗，戴不进去），换成**挂坠类**头部饰品 +1

**玩法定位**：重装近战和锻造生活职业的最佳起点。心智 D 意味着咒术线基本无缘。

---

### 艾沃人

**东部大森林的原住民，氏族社会。**

**外形**：瘦高，皮肤带一层淡淡的青色，在林子里不动的时候看不见。瞳孔偏金。头发黑且硬，扎成束。

**生理**：汗液是树木的气味，蚊虫不近身。能靠树皮的震动判断林子里有没有大兽——不是魔法，是从小练出来的耳朵。

**社会**：以氏族为单位，《林界约》之后半独立于王国。艾沃人卖木材和药材，但砍自家林子的树要先"问树"——手贴上去待一炷香，再决定。

**习俗**：不打猎怀崽的兽，不吃会说话的鸟。成年礼是独自在林子里过一个月。

> 「树不会躲你。是你没学会看它。」——艾沃猎手教徒弟

**属性**：体魄 D · 灵巧 B · 心智 C · 感知 A · 魅力 C · 意志 C

**特殊能力**：
- 被动 **林息**：森林地形潜行自动成功；草木茂密处恢复速度 +30%
- 主动 **问树**：摸树可知 50 米内大型生物的位置（每日三次）
- 出身 **林权**：东部森林采集不需要许可证

**装备槽**：基准 10 槽，背部槽可装**翼外挂**（艾沃人惯用背架），躯干槽默认是皮质软甲

**玩法定位**：远程与探索线首选。感知 A 支撑侦察和瞄准，体魄 D 让正面打架很吃亏。

---

### 哈兰人

**西部草原的游牧民族，牧盟的骨架。**

**外形**：肤色晒成深棕，腿长而韧。小腿肌肉是站马上练出来的——哈兰人小孩先学骑再学走（夸张，但不多）。

**生理**：平衡感极佳，能在奔跑的马背上睡觉。乳糖消化极好（草原饮食全是奶）。

**社会**：八个部族一年聚两次（春场、秋场），平时各自沿水草迁徙。没有王，有事各部族长老议事，吵到统一为止。近年年轻人进城市当骑手、护路军骑兵，长老们摇头但拦不住。

**习俗**：待客先上奶茶，喝三碗才有资格谈事。马死了要埋不要吃（饥年除外，但要给马唱歌）。

> 「地上没有你的家。你的家跟着你走。」——哈兰母亲教女儿

**属性**：体魄 C · 灵巧 B · 心智 D · 感知 C · 魅力 B · 意志 B

**特殊能力**：
- 被动 **马背民族**：所有坐骑速度 +15%，马上战斗无惩罚
- 主动 **换马**：坐骑受重伤时瞬移换乘备马（需备马，每日一次）
- 出身 **牧道**：知道地图上不标的水源和便道

**装备槽**：基准 10 槽，**鞋靴槽默认是马靴**（步行惩罚 +5%，骑乘加成 +10%）

**玩法定位**：机动作战与商队线。心智 D 不是问题——草原人不觉得读书比骑马重要。

---

### 岬人

**南部海岸的渔民民族，白帆商盟的水手。**

**外形**：肩背宽，手指间有退化到看不出的蹼痕。耳廓会不自觉动（潜水时闭耳压的习惯）。肤色深。

**生理**：**潜水五分钟**不是仪器，是脾脏储血的能力——这是岬人身体真正特别的地方。憋气时间三倍于常人。

**社会**：港城社会围绕船籍。船籍比姓氏重要，问一个岬人"你是哪条船的"比问他姓什么更有礼貌。女子当家（丈夫常年出海，账和船都归妻子管）。

**习俗**：出海前不说不吉利词的**谐音**。船上第一网鱼扔回海里一条。

> 「海不欠你。海只是脾气大。」——老船长

**属性**：体魄 C · 灵巧 B · 心智 C · 感知 B · 魅力 C · 意志 D

**特殊能力**：
- 被动 **深潜**：水下活动时间 ×3，水下视野清晰
- 主动 **浪里翻**：水中闪避必成功（每日两次）
- 出身 **船籍**：所有港城的码头设施免费使用

**装备槽**：基准 10 槽，**鞋靴槽不能穿金属重靴**（脚蹼结构不适合）

**玩法定位**：涉水战斗和海岛探索。意志 D 使他们怕痛苦类异常状态。

---

### 岩民

**北方高地背阴谷的慢种族，砂岩一样的皮肤。**

**外形**：矮而厚重，皮肤是带纹理的灰色，像砂岩。没有毛发。眼睛是两粒黄晶。走路很慢，说话更慢。

**生理**：新陈代谢极慢——**两天吃一顿，一周睡一次**，能活四百岁。伤口愈合慢，但几乎不生病。怕掉进水里：岩民沉得像真的石头。

**社会**：岩民社会没有"急"这个概念。他们记得高地两百年前每一次矿难的死者名单，一代一代往下背。岩民做门卫、档案保管员、石匠——**任何需要"永远不变"的岗位**。

**习俗**：不说"再见"，说"还会见"（反正能等）。给人担保是大事，一旦担保终身不改。

> 「你们的墙坏了，因为你们只肯修一次。」——岩民石匠

**属性**：体魄 B · 灵巧 D · 心智 C · 感知 C · 魅力 C · 意志 A

**特殊能力**：
- 被动 **磐体**：睡眠需求 -85%，饥饿减速；**溺水即沉底**（移除浮力，可沿水底行走）
- 主动 **石化肤**：受击硬直免疫 10 秒，期间不能移动（每战一次）
- 出身 **档籍**：静纹院与行会的档案可自由调阅（看到别人看不到的历史）

**装备槽**：基准 10 槽，**不能穿任何"贴身"材质**（布、皮直接接触皮肤会磨损岩皮），护甲类必须衬铁

**玩法定位**：坦克与守卫玩法。意志 A 抗石纹与恐惧，灵巧 D 永远躲不开攻击——但岩民本来就不躲。

---

### 傀人

**工厂造出来的机关劳工，正在"变成人"的路上。**

**外形**：铁壳包黄铜关节，胸腔里是一台小辉石炉，透出淡青光。脸部是一块平板，上面刻着编号（有的傀人后来自己改了刻痕，像是表情）。

**生理**：不吃、不睡、不呼吸。胸腔炉就是"心脏"，辉石是"饭"。第九批之后的傀人开始**怕疼**——商会说是零件公差，没人信。

**社会**：法律上傀人是**商会的财产**。炉历 121 年后，一台战地傀人自己走进静纹院要求"存档"，此案打到现在（"傀人诉讼案"）。如今城市里的傀人分三种：在册（商会财产）、赎身（攒钱买下自己）、野籍（编号被注销，下落不明）。

**习俗**：傀人没有习俗——**但他们开始有了**。在册傀人下班后会站在路灯下看灯，一站一小时。没人教过他们这个。

> 「我修了三十年的傀。最近十年，我不敢再看它们的脸——虽然那上面什么都没有。」——铎港老机师

**属性**：体魄 A · 灵巧 C · 心智 D · 感知 C · 魅力 C · 意志 B

**特殊能力**：
- 被动 **铁身**：不吃不睡；毒素、出血免疫；**治疗咒术对傀人无效**（只能"修理"——用机工道具回血）
- 主动 **超载**：胸腔炉过载 10 秒，全属性 +50%，之后冷却 1 小时（每日两次）
- 出身 **编号**：工厂区通行无阻；野外宿营地不需要食物补给

**装备槽**：基准 10 槽，但**护甲槽形制特殊**（傀人装甲，与人类装备池半隔离）；**饰品槽只能装"炉芯挂件"**

**玩法定位**：极限的生存者与力量型。心智 D 加上"治疗无效"，玩傀人等于换了一套生存逻辑。

---

### 纹人

**纹城的施术民族，天生带着石纹出生。**

**外形**：和洛文人几乎一样，但手臂上天生有淡淡的纹路——刚出生像胎记，成年后开始发光。纹人的眼睛在暗处是亮的。

**生理**：**生下来就是"手纹"级石纹**，而且纹路天生稳定（不会爬向胸口）。代价是寿命：纹人平均活五十岁（常人七十）。他们的石纹是"生而对齐"的，引能量不需要像外族那样先"破皮"。

**社会**：纹城是咒术行会总部，纹人是行会的"血统贵族"。外族学咒术要从无纹开始熬，纹人起步就领先十年——**行会内部也因此分两派，互相看不上**。

**习俗**：纹人葬礼没有墓，遗体放在静纹院回廊，让它自然完成石化——纹人管自己的终点叫"**到家**"。

> 「外族人学引咒，像学一门手艺。我们学走路。」——纹城老咒师

**属性**：体魄 D · 灵巧 C · 心智 A · 感知 C · 魅力 B · 意志 C

**特殊能力**：
- 被动 **生而对齐**：开局即二阶咒文；石纹增长速度 -30%
- 主动 **借纹**：主动加速石纹爬升，换一次高阶咒文爆发（自主选择何时付出代价）
- 出身 **行会籍**：咒术行会的咒文库全开

**装备槽**：基准 10 槽，**躯干槽不能穿金属甲**（贴身金属会干扰引咒，行会规矩也是物理事实）

**玩法定位**：施术线专属起点。心智 A + 生而对齐让它成为最强施咒种族，代价是体魄 D 与五十岁的人生。

### 翎人

**东南高原崖壁上的滑翔民族。**

**外形**：瘦削轻骨（骨头是中空的，体重只有同体型人的一半），臂侧到腰有可收拢的皮膜，展开是一对三角翼。收拢时像披了件宽斗篷。

**生理**：**从高处跳下能滑翔**——不是飞，是滑。滑翔比降 1:4（掉一米滑四米）。骨头轻，所以摔不得：被击落时伤害翻倍。

**社会**：翎人住在崖壁凿出的巢屋，氏族以"哪面崖"区分。他们当信使、测绘员、了望手——**王家测绘局里翎人比例最高**（用滑翔勘察地形）。铁路时代到来后，翎人信使行业被火车碾压，正在集体转行。

**习俗**：孩子成人礼从崖上跳下（下面有网，但没人告诉你网在不在——这是玩笑，网永远在）。翎人不说"死"，说"落地"。

> 「你们在地面画线，我们在天上看得见线往哪儿弯。」——翎人测绘员

**属性**：体魄 C · 灵巧 A · 心智 C · 感知 B · 魅力 C · 意志 D

**特殊能力**：
- 被动 **滑翔**：高处下落改为滑翔，坠落伤害仅在被击落时计算（且翻倍）
- 主动 **俯瞰**：升空盘旋 30 秒，本区域地图点亮、敌人位置标记（每日一次）
- 出身 **崖籍**：高原与山地地形移动无惩罚

**装备槽**：基准 10 槽，**背部槽天然被翼膜占用**（不能装背包与背甲），换来**翼膜专属槽**（翼装备，全种族唯一）

**玩法定位**：侦察、狙击、地图探索。灵巧 A 配远程，意志 D 配"挨了打很惨"。

| 翎人 | 9 | 背部锁翼膜槽（翼装备，全种族唯一） |

**多肢体、翅膀、背部装备的实现全部依托这张表**——不是给数值加成，是每个种族的身体本来就长这样。
