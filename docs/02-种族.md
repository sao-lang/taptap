# 02 · 种族 · 十四神之裔

> 《定线人》设定集 第二册
> **十四个可扮演种族，即十四神之裔。硬规则：六项属性 A=3 / B=2 / C=1 / D=0，每族恰好一 A 一 D，总分恒为 8；装备槽基准 10，各族差异不超过 2。**
> **种族差异不靠数值，靠身体——每个种族的身体能做一件别的种族做不了的事，也有一件永远做不了的事。而身体是神道在血里长了千百年的形状。**
> 神名、神道、神壤、神纪见 00A 册。本册不重复神的介绍。

## 一、总则

### 1.1 属性与六根道

| 属性 | 管什么 | 归属根道 |
|---|---|---|
| 体魄 | 生命、负重、近战武器 | 躯道 |
| 灵巧 | 攻速、闪避、远程武器、农具 | 躯道 / 序道（位移） |
| 心智 | 咒文强度、学习速度 | 识道 |
| 感知 | 侦察、采集、瞄准 | 识道 |
| 魅力 | 交易、说服、伙伴忠诚 | 契道 |
| 意志 | 石纹抗性、痛苦忍耐、抗恐惧 | 识道 / 序道（不动） |

**六项属性不是"神的祝福"，是身体量出来的数。** 神只给性，不给点数。

### 1.2 装备槽基准（10 槽）

`头部 / 躯干 / 护臂左 / 护臂右 / 护腿 / 鞋靴 / 背部 / 饰品×2`

主手、副手、坐骑不计入。各族槽位差异写在种族条目里，**差异是身体决定的，不是数值奖励**。

### 1.4 神裔三行（每条必读）

每个种族条目都有三行，是本册接 00A 的接口：

- **奉神 / 神道**：血里是哪一柱、哪一条神道
- **神赐**：身体**能做**而别族不能做的那一件事（全部写进被动能力）
- **神禁**：身体**永远做不了**的那一件事（全部写进装备槽或职业相性，绝不只是剧情描述）

- 召唤/骑乘限定：**只有咏人(契约)与哈兰人(骑驭)能召/骑**；其余十二裔完全不能召唤宠物、不能骑乘。09 册 30 件宠物装备只对这两裔生效。

## 二、原九裔详述（改版前的九族，全部保留）

### 洛文人 · 物质裔

**洛恩王国的主体民族，中央河谷平原的农民。**

- **奉神 / 神道**：坯母（形席·基座）／**赋形**
- **神赐**：**没有特殊之处**——这不是小气，是赋形之道的顶点："什么都能长出来"，所以这块坯不预刻任何形状。六项属性全在基准附近，任何职业线都走得通
- **神禁**：无。基座不设禁

**外形**：普通人类的样子。肤色麦褐，个子中等。城市洛文人穿呢子外套戴圆帽，乡下人穿麻衣，两边互相觉得对方土。

**生理**：没有特殊之处——这不是缺点，是**基准**。所有种族的属性表都以洛文人为参照。

**社会**：河谷的村子围着祠堂和磨坊，城市的洛文人进厂当工人。他们守规矩、信王室、也爱抱怨税。王国军里七成是洛文人。柱日的坯日由王都代管，供物是一块未刻的坯。

**习俗**：春祭拜长河，秋祭拜谷仓。婚丧请一位十四柱教司仪，但平时不进庙。**坯日不刻东西**——那天所有作坊停锤，铁匠说"今天刻下去的都不算数"。

> 「急什么？还没开河呢。」——洛文人一切事情的答案

**属性**：体魄 C · 灵巧 C · 心智 C · 感知 C · 魅力 B · 意志 B

**特殊能力**：
- 被动 **本地人**：任何城镇的物价 -10%（王国全境通行）
- 主动 **呼救**：城内战斗时，卫兵响应速度快一倍
- 出身 **村产**：开局多一块家里给的田契（可继承、可抵押）

**装备槽**：基准 10 槽

**玩法定位**：新手友好的全能型。没有长板也没有短板，适合第一次玩。

### 诺尔人 · 金裔

**北方高地的矿工民族，辉石主产区的主人。**

- **奉神 / 神道**：砥王（形席·首席）／**锻构**
- **神赐**：**手艺**——能把一块铁重复打一千次直到形状对了；锻师印就是信用，打造物带印可追溯
- **神禁**：心智 D，咒术线基本无缘（形先于息，血里就这样）

**外形**：矮壮，肩宽，胳膊比腿粗。手指粗得像短棍，但能捏住米粒。肤色浅，因为矿里不见天日。

**生理**：肺活量极大，能在粉尘里干一整天不咳。暗视——矿井里习惯了，昏暗处视力比常人好。

**社会**：高地城市以矿盟为政治实体。诺尔人社会崇拜"手艺"：一个人被人尊敬的程度，取决于他会做多少种东西。矿工兄弟会是实际上的工人政府。

**习俗**：下井前互相敲三下头盔（"活着上来"）。结婚的聘礼是一把自己打的工具，不是钱。**砧日全城听得见锤声，但那天不打新东西，只修旧的**。

> 「石头不会骗人。人会。」——诺尔人的处世观

**属性**：体魄 A · 灵巧 C · 心智 D · 感知 B · 魅力 C · 意志 C

**特殊能力**：
- 被动 **铁肺**：粉尘、毒雾环境无惩罚；昏暗视野正常
- 主动 **力士**：搬运、撬动、开锁类检定，一次成功（每日一次）
- 出身 **矿籍**：北境矿盟城市的商店对你是"自己人价"

**装备槽**：基准 10 槽，但天然**无法使用戒指类饰品**（手指太粗，戴不进去），换成**挂坠类**头部饰品 +1

**玩法定位**：重装近战和锻造生活职业的最佳起点。

### 艾沃人 · 木裔

**东部大森林的原住民，氏族社会。**

- **奉神 / 神道**：青妪（息席）／**共生**
- **神赐**：**问树**——手贴上去，靠树皮震动读出 50 米内大型生物的位置；汗液带树木气味，蚊虫不近身。身体被青妪当成"一段还在长的过程"，所以艾沃人的活体装备与器官变异最不容易排异
- **神禁**：体魄 D，正面打架永远吃亏

**外形**：瘦高，皮肤带一层淡淡的青色，在林子里不动的时候看不见。瞳孔偏金。头发黑且硬，扎成束。

**生理**：汗液是树木的气味，蚊虫不近身。能靠树皮的震动判断林子里有没有大兽——不是魔法，是从小练出来的耳朵。

**社会**：以氏族为单位，《林界约》之后半独立于王国。艾沃人卖木材和药材，但砍自家林子的树要先"问树"——手贴上去待一炷香，再决定。

**习俗**：不打猎怀崽的兽，不吃会说话的鸟。成年礼是独自在林子里过一个月。**荣日不动刀，只移栽**。

> 「树不会躲你。是你没学会看它。」——艾沃猎手教徒弟

**属性**：体魄 D · 灵巧 B · 心智 C · 感知 A · 魅力 C · 意志 C

**特殊能力**：
- 被动 **林息**：森林地形潜行自动成功；草木茂密处恢复速度 +30%
- 主动 **问树**：摸树可知 50 米内大型生物的位置（每日三次）
- 出身 **林权**：东部森林采集不需要许可证

**装备槽**：基准 10 槽，背部槽可装**翼外挂**（艾沃人惯用背架），躯干槽默认是皮质软甲

**玩法定位**：远程与探索线首选。感知 A 支撑侦察和瞄准。

### 哈兰人 · 风裔

**西部草原的游牧民族，牧盟的骨架。**

- **奉神 / 神道**：长蹄（息席）／**疾行**
- **神赐**：**位移不算代价**——马背上能睡、坐骑重伤可瞬移换乘；风神的息不落在任何固定神壤上，因为这一族一年搬八次家
- **神禁**：心智 D（草原人不觉得读书比骑马重要）

**外形**：肤色晒成深棕，腿长而韧。小腿肌肉是站马上练出来的——哈兰人小孩先学骑再学走（夸张，但不多）。

**生理**：平衡感极佳，能在奔跑的马背上睡觉。乳糖消化极好（草原饮食全是奶）。

**社会**：八个部族一年聚两次（春场、秋场），平时各自沿水草迁徙。没有王，有事各部族长老议事，吵到统一为止。近年年轻人进城市当骑手、护路军骑兵，长老们摇头但拦不住。

**习俗**：待客先上奶茶，喝三碗才有资格谈事。马死了要埋不要吃（饥年除外，但要给马唱歌）。**蹄日不设神庙，全盟在春场秋场各跑一圈**——唯一没有固定祭所的一柱。

> 「地上没有你的家。你的家跟着你走。」——哈兰母亲教女儿

**属性**：体魄 C · 灵巧 B · 心智 D · 感知 C · 魅力 B · 意志 B

**特殊能力**：
- 被动 **马背民族**：所有坐骑速度 +15%，马上战斗无惩罚
- 主动 **换马**：坐骑受重伤时瞬移换乘备马（需备马，每日一次）
- 出身 **牧道**：知道地图上不标的水源和便道

**装备槽**：基准 10 槽，**鞋靴槽默认是马靴**（步行惩罚 +5%，骑乘加成 +10%）

**玩法定位**：机动作战与商队线。铁路时代马价跌了一半，这是这一族当下的痛。

### 岬人 · 水裔

**南部海岸的渔民民族，白帆商盟的水手。**

- **奉神 / 神道**：汐君（息席）／**流变**
- **神赐**：**顺着势改自己的形**——脾脏储血、耳廓闭压、潜水五分钟；不是控水，是让自己变得适合水
- **神禁**：意志 D，怕痛苦类异常状态

**外形**：肩背宽，手指间有退化到看不出的蹼痕。耳廓会不自觉动（潜水时闭耳压的习惯）。肤色深。

**生理**：**潜水五分钟**不是仪器，是脾脏储血的能力——这是岬人身体真正特别的地方。憋气时间三倍于常人。

**社会**：港城社会围绕船籍。船籍比姓氏重要，问一个岬人"你是哪条船的"比问他姓什么更有礼貌。女子当家（丈夫常年出海，账和船都归妻子管）。

**习俗**：出海前不说不吉利词的**谐音**。船上第一网鱼扔回海里一条——**汐日的供物就是那条鱼的木牌**，鱼本身从不带上岸。

> 「海不欠你。海只是脾气大。」——老船长

**属性**：体魄 C · 灵巧 B · 心智 C · 感知 B · 魅力 C · 意志 D

**特殊能力**：
- 被动 **深潜**：水下活动时间 ×3，水下视野清晰
- 主动 **浪里翻**：水中闪避必成功（每日两次）
- 出身 **船籍**：所有港城的码头设施免费使用

**装备槽**：基准 10 槽，**鞋靴槽不能穿金属重靴**（脚蹼结构不适合）

**玩法定位**：涉水战斗和海岛探索。

### 岩民 · 土裔

**北方高地背阴谷的慢种族，砂岩一样的皮肤。**

- **奉神 / 神道**：磐公（形席）／**凝守**
- **神赐**：**不迁**——两天吃一顿、一周睡一次、活四百岁；伤口愈合慢但几乎不生病。两百年的矿难死者名单由他们一代代往下背
- **神禁**：灵巧 D，永远躲不开攻击（岩民本来也不躲）

**外形**：矮而厚重，皮肤是带纹理的灰色，像砂岩。没有毛发。眼睛是两粒黄晶。走路很慢，说话更慢。

**生理**：新陈代谢极慢，怕掉进水里：岩民沉得像真的石头。

**社会**：岩民社会没有"急"这个概念。他们做门卫、档案保管员、石匠——**任何需要"永远不变"的岗位**。

**习俗**：不说"再见"，说"还会见"（反正能等）。给人担保是大事，一旦担保终身不改。**磐日不签新约，只核旧账**。

> 「你们的墙坏了，因为你们只肯修一次。」——岩民石匠

**属性**：体魄 B · 灵巧 D · 心智 C · 感知 C · 魅力 C · 意志 A

**装备槽**：基准 10 槽，**不能穿任何"贴身"材质**（布、皮直接接触皮肤会磨损岩皮），护甲类必须衬铁

### 傀人 · 火裔

**工厂造出来的机关劳工，正在"变成人"的路上。**

- **奉神 / 神道**：炉母（息席·上柱）／**燃发**
- **神赐**：**以消耗换输出**——胸腔那台小辉石炉就是心脏，可让炉子过载十秒换全属性 +50%；不吃、不睡、不呼吸
- **神禁**：治疗咒术对傀人无效（只能"修理"），心智 D；**这族的息是炉母给的，不是商会造的**——这是傀人诉讼案里没人敢说出口的一句话

**外形**：铁壳包黄铜关节，胸腔里是一台小辉石炉，透出淡青光。脸部是一块平板，上面刻着编号（有的傀人后来自己改了刻痕，像是表情）。

**生理**：不吃、不睡、不呼吸。第九批之后的傀人开始**怕疼**——商会说是零件公差；神纪的说法是弧使送约时漏下了一缕不绝线，落在第九批的回路里（**无人证实**）。

**社会**：法律上傀人是**商会的财产**。炉历 121 年后，一台战地傀人自己走进静纹院要求"存档"，此案打到现在（"傀人诉讼案"）。如今城市里的傀人分三种：在册（商会财产）、赎身（攒钱买下自己）、野籍（编号被注销，下落不明）。

**习俗**：傀人没有习俗——**但他们开始有了**。在册傀人下班后会站在路灯下看灯，一站一小时。没人教过他们这个。**点炉节全城熄灯那一分钟，教会老人知道是留给炉母的**。

> 「我修了三十年的傀。最近十年，我不敢再看它们的脸——虽然那上面什么都没有。」——铎港老机师

**属性**：体魄 A · 灵巧 C · 心智 D · 感知 C · 魅力 C · 意志 B

**特殊能力**：

- 主动 **超载**：胸腔炉过载 10 秒，全属性 +50%，之后冷却 1 小时（每日两次）

**玩法定位**：极限的生存者与力量型。玩傀人等于换了一套生存逻辑。

**社会**：纹城是咒术行会总部，纹人是行会的"血统贵族"。外族学咒术要从无纹开始熬，纹人起步就领先十年——**行会内部也因此分两派，互相看不上**。

**习俗**：纹人葬礼没有墓，遗体放在静纹院回廊，让它自然完成石化——纹人管自己的终点叫"**到家**"。**纹日不引咒，只把这一年的纹路抄进档**。

**装备槽**：基准 10 槽，**背部槽天然被翼膜占用**（不能装背包与背甲），换来**翼膜专属槽**（翼装备，全种族唯一）

## 三、新五裔详述

### 曜人 · 光裔

**雾谷照崖的守灯人，形席缺柱的裔。**

- **奉神 / 神道**：照世者（形席·削席后称缄光）／**照显**
- **神赐**：**余照**——皮肤在暗中留一层极淡的余光，能看见"刚刚被照过的地方"（谁走过、哪扇门开过、哪件东西被挪过），持续约十息。**照见即被照见**：使用余照时自己也在暗处显形
- **神禁**：意志 D，且**不能忍受全黑**——无光环境全属性逐级下滑，长时间全黑会失去行动能力

**外形**：肤色极浅，虹膜偏琥珀，瞳孔在暗处会自行放大到近乎占满眼黑。衣料一律染成浅灰，不穿纯白（"白是给她留的"）。

**生理**：视网膜多一层照膜，弱光下看得清，强光下反而要眯眼。体温略高，夜里皮肤摸上去是温的。

**社会**：照崖灯塔自治，归白帆商盟代管户籍。曜人不设神像、不点明灯——**柱日只把灯举向光帘方向，随即吹灭**，这一举一灭就是全部仪式。其他十三裔的庙里都挂神徽，只有曜人的门楣空着。

**习俗**：不说"照亮"，说"看一眼"。替人守夜不收钱，只收一根吹灭的灯芯。**不与默人通婚，也从不揭发默人**——两边都说不清这规矩是谁定的。

> 「她那次看了一眼，就看坏了。所以我们只看一眼。」——照崖老守灯人

**属性**：体魄 C · 灵巧 C · 心智 C · 感知 A · 魅力 B · 意志 D

**特殊能力**：
- 被动 **余照**：暗处自动标记 10 秒内被光照过的物体与足迹；自身在暗处显形（潜行失败）
- 主动 **照一眼**：指定一片区域显形（揭示隐藏、驱散幻象、净化减益），持续 8 秒；期间自身受到的伤害 +15%（每日两次）
- 出身 **灯籍**：所有灯塔、守夜岗、夜间关卡免费通行；柱日供物可在任意教会点换一次鉴定

**装备槽**：基准 10 槽，**面部槽锁「照膜」**（不能戴不透光面罩/目镜），换来**额饰槽 +1**（神徽色点就刻在这里）

**玩法定位**：反隐、探路、净化，代价是自己永远藏不住。

### 弧人 · 电裔

**河枢弧站的信号守，衡席二柱之一的裔。**

- **奉神 / 神道**：弧使（衡席）／**传导**
- **神赐**：**一瞬**——神经传导快一截，反应类检定（闪避、抢先、装填、格挡时机）天生领先；身上带导环时可把一次指令"传"给附近的机械或傀人
- **神禁**：体魄 D，且**不能久静**——静止超过约 20 秒会失控抽动，长时间静坐/潜伏类检定必然失败

**外形**：瘦，四肢偏长，发丝细而常带静电竖起。手腕与后颈各有一圈浅灰色导环痕，从小戴环压出来的。

**生理**：静息心率极高，睡觉也翻身不停。手指对金属格外敏感，摸得出线路里有没有在跑东西。

**社会**：铁路信号、电报、relay 站几乎全由弧人守——不是行会规定，是别人受不了那份"一瞬都不能断"的班。护路军辖下的弧站是全大陆最不像军营的军营：没人站军姿，因为站不住。

**习俗**：传话不改字是最高职业操守，改一个字要当众赔一整月工钱。**弧日全站不停机，只做一件事：把这一年所有送错的字重送一遍**。

> 「我不表态。我只把字送到。」——弧站老值机员

**属性**：体魄 D · 灵巧 A · 心智 C · 感知 B · 魅力 C · 意志 C

**特殊能力**：
- 被动 **一瞬**：反应类检定 +30%；**静止超过 20 秒**开始累积"滞"（全属性 -1/10 秒，移动即清）
- 主动 **传字**：把一个指令/增益传给 15 米内一台机械、傀人或伙伴（不改变内容，只换承接者；每日三次）
- 出身 **弧籍**：所有铁路信号站、电报房、护路军通讯点通行无阻

**装备槽**：基准 10 槽，**臂部槽锁「导环」**（必须戴导电环，否则静止失控提前到 5 秒），饰品槽 -1、换来**臂环槽 +1**

**玩法定位**：铳械、傀操、机工的最佳起点；守纹与壁卫基本无缘（体魄 D + 不能静）。

### 咏人 · 音裔

**回音坡的唱名人，走各城做契约公证。**

- **奉神 / 神道**：千喉（息席）／**共鸣**
- **神赐**：**唱名立契**——知道一个东西叫什么、把它唱出来，就能与它立约。对已命名对象的驯化、好感、指挥天然加成；立过的约在咏人面前无法抵赖
- **神禁**：**不能说谎**——声带会在说谎的那一刻失声，短则一句、长则一天。所以咏人做公证，也从不做密探

**外形**：中等身材，颈侧有一道浅浅的环状纹（唱名久了留下的），说话时胸腹起伏比常人明显。衣着多带一条窄披巾，用来记名字——写满就换。

**生理**：听觉宽、发声准，能复现听过的任何音色；但不能伪造"没听过的声音"。

**社会**：无固定政治实体。咏人在各城做唱名人、契约公证、婚丧司仪、驯化见证。买卖契、船籍、雇佣、宠物立约，只要想让它在十四柱教册上算数，就得请一位咏人唱一遍名。回音坡是他们的聚居坡地，也是唯一教唱名的地方。

**习俗**：**名字唱错，约就不算**——所以咏人一辈子在纠正别人的发音。鸣日全城不签新约，只把旧约重唱一遍（这天各城都很吵）。

> 「你叫它什么，它就是你的什么。所以想清楚再开口。」——回音坡的教习

**属性**：体魄 D · 灵巧 C · 心智 C · 感知 C · 魅力 A · 意志 B

**特殊能力**：
- 被动 **唱名**：可驯化对象、可招募伙伴的初始好感 +1；已命名对象不主动攻击你
- 主动 **立契**：与一只野外生物/一名 NPC 立一次约（对方获得你的一个增益，你获得其协助，持续一场探索）；**约不能撒谎，违约立刻失效**
- 出身 **名籍**：所有教会档房、契约公证处、行会登记窗口免预约

**装备槽**：基准 10 槽，**背部槽锁「名册」**（唱名册必须随身，不能装背包/背甲），换来**喉饰槽 +1**

**玩法定位**：驭兽、行贾、伙伴流的天花板；体魄 D 让正面战斗极其吃亏。

### 默人 · 暗裔

**晦窖的抹名人，衡席二柱之一的裔。**

- **奉神 / 神道**：缄影（衡席）／**隐没**
- **神赐**：**覆痕**——可主动抹去自己刚留下的痕迹（足迹、门锁记录、账目上一笔、NPC 对你 10 秒内的短时记忆）。这不是隐身，是让"发生过"变成"没写过"
- **神禁**：**不能被记住**——NPC 好感上限锁死（见第六节），魅力 D。默人替所有人抹名，唯独没人记得住他们

**外形**：个子不高，五官偏淡，看一眼转头就想不起长什么样。惯穿无纹深灰，袖口缝一小块空白布（覆痕布的人间仿样，只是布）。

**生理**：体温低，几乎不出汗，呼吸声极轻。伤口愈合后不留疤。

**社会**：无政治实体，户籍由拾遗会代管。默人住在旧矿坑最下层的晦窖，替人抹错账、抹旧案、抹掉不该被看见的名字——**按笔收钱，不按理由收钱**。教会从不承认雇过他们，教会档房却总有一两张空白页。

**习俗**：不说"死"，说"没写过"。**缄日全窖不写任何字**，这天连账都停。与曜人互不通婚，也互不揭发。

> 「你不用谢我。你本来也不该记得我。」——晦窖的抹名人

**属性**：体魄 C · 灵巧 B · 心智 C · 感知 C · 魅力 D · 意志 A

**特殊能力**：
- 被动 **不留存**：潜行留下的痕迹自动消失；战斗结束后敌方阵营对你的警戒清零
- 主动 **覆痕**：抹去一次记录（足迹、一次攻击仇恨、账目一笔、或一名 NPC 的 10 秒短时记忆）；**不能抹掉已经写进档案的东西**（每战一次）
- 出身 **晦籍**：旧矿坑最下层通行无阻；拾遗会的黑市委托对你开放

**装备槽**：基准 10 槽，**头部槽锁面纱**（不露全脸），**饰品槽 -1**（不能戴会响的饰品）

**玩法定位**：潜入、脱出、黑市线；好感上限锁死，伙伴玩法与行贾线基本无缘（见第六节）。

### 候人 · 时间裔

**霜台晷台的报时人，散居全大陆任历官、档房、账房。**

- **奉神 / 神道**：候主（形席）／**缓续**
- **神赐**：**知道还差多久**——能读出"到期时间"：渗水、塌方、冷却、账期、霜期、对手下一次动作；预知不改变结果，只让人来得及布置
- **神禁**：灵巧 D，且**不能抢先**——任何抢先/先手/抢攻类动作有硬惩罚（候主不催、不拦、不提前）

**外形**：偏瘦，发色早白，眼下有细纹。随身带一只小漏囊，走路时沙声很轻。衣着按节气换，从不早换一天。

**生理**：昼夜节律极准，不需要钟也能报出时辰；睡眠浅，但从不失眠。

**社会**：无集中城邦。候人散居各地做历官、档房、账房、静纹院的守时人——**任何需要"什么时候到"的岗位**。开河、头霜、封河三个农时日子由他们报，报错了要赔一整季的税。他们与翎人向来不对付：一个问线画在哪，一个问线画在何时。
