# 11 · 载具与改装

> 《定线人》设定集 第十一册
> 5 种载具（各有承神）、固定改装槽位、46 件载具装备（按六根道归类）。

---

## 一、载具的定位

**载具不是交通工具，是"移动的基地"。**

野外过夜是致命的。载具承担三个功能：移动、存续、战斗。

**载具会坏，而且修不起。** 这个世界没有 4S 店，坏了要自己拆、自己焊。这给"采集"和"制造"一个硬需求。

## 二、五种载具

### 2.1 板车

|---|---|
| 地形 | 荒野泥地、浅水 |
| 速度 | 15 km/h |
| 载重 | 200 kg |
| 耐久 | 120 |

**特点**：淹不死（浮得起），但怕浪。大潮日不能出。

**特点**：只能在铁轨和平直道上跑。**主线干线东段的未通车段，只有轨道车能提前通行**——这是玩家比火车先到达未开发区域的唯一方式。

### 2.4 战车

| 项目 | 内容 |
|---|---|
| 地形 | 陆（干燥地面） |
| 速度 | 18 km/h |
| 载重 | 1200 kg |
| 耐久 | 900 |
| 座位 | 1 驾驶 + 3 炮手 |
| 燃料 | 辉石（耗量大） |

**固定槽位（6）**：`chassis` 底盘 · `engine` 引擎 · `turret` 炮塔 · `side` ×2 侧挂 · `armor` 装甲

**为什么这个世界有战车**：护路军与矿区佣兵的冲突、以及旧矿坑深处的机械兽群，都需要"能扛的东西"。战车不是为战争造的，是为"护送"造的。

| 项目 | 内容 |
|---|---|
| 地形 | 空中 |
| 速度 | 75 km/h |
| 载重 | 120 kg |
| 耐久 | 100 |
| 座位 | 1 驾驶 + 1 乘客 |
| 燃料 | 辉石（高纯） |
| 获取 | 王家测绘局，40000 辉票（需主线第 16 章） |

## 载具承神

| 载具名 | 承神 | 为什么 | 对应神壤 |
|---|---|---|---|
| **板车** | 风 · 埃俄隆 | 无引擎、人力/风力，淹不死浮得起，靠"位移不算代价"吃下荒野泥地与浅水；最便宜的入场券就是**莱恩**"家跟着人走"的形状（00A 7.6）。玩家想：它不是车，是能拖着走的脚力，别指望它扛重 | 莱恩 · 西部草原 |
| **河船** | 水 · 涅瑞娅 + 火 · 伊格妮丝（双承） | 吃水 1.5m、退潮搁浅、只在涨潮与海面内河走，随流改形是**流变**；装了螺旋桨与辉石炉才逆风也能走，那一程是**燃发**烧出来的（00A 7.3 / 7.4）。玩家想：看潮行车，炉子烧的是一次性输出 | 玛瑞 · 南部海岸 / 阿什卡兰 · 铎港炉区 |
| **轨道车** | 物质 · 希莱昂 + 金 · 奥瑞恩（双承） | 1500kg 载重、只在铁轨与平直道跑、移动仓库——希莱昂给重量与承载，奥瑞恩给轨与"有印才算数"的耐久，是**赋形**与**锻构**；河枢机务段的信号、电报、电池件走电 · 考恩（刻拉诺斯**传导**），但车身只承前两柱。玩家想：这是比火车先到未通车段的唯一工具，改装台认铁砧 | 瓦伦 · 中央河谷 / 维尔达 · 北境高地 |
| **战车** | 金 · 奥瑞恩 | 铁砧定制、装甲与炮塔、耐久 900、为"护送"造的陆地堡垒——凡有印、有刃、有甲处皆在**锻构**范围内（00A 7.1）。玩家想：战车不比速度，拼的是扛住的那一阵，零件回铁砧配 | 维尔达 · 北境高地 |
| **飞行器** | 空间 · 托帕佐斯 | 王家测绘局与阿斯特里人合造的"测绘翼机"（滑翔翼＋辉石引擎）、没有战斗力、被击中就掉——**挪移**管界线、距离、地图与"从高处看得见线往哪儿弯"（00A 7.12）。玩家想：它是开图的眼，不是坐骑，别拿它打架 | 鲁涅特 · 望崖 |

**火车**归物质与金两柱共承（希莱昂给重量、奥瑞恩给轨），**辉石船**归水与火（涅瑞娅给流、伊格妮丝给炉），这是全表唯一双承的例外。表中对应的就是**轨道车**（跑铁路干线）与**河船**（烧辉石炉的那一条），其余三辆各承一柱。承神不换属性、不给保佑，只定三件世俗事：改装台回哪座城、柱日哪天相关铺子停业、拆下来的部件走哪门鉴定（见 06 册）。

## 三、改装规则

### 3.1 三重约束

| 约束 | 说明 |
|---|---|
| **重量** | 每个底盘有载重上限。装重甲就装不了大货箱 |
| **功率** | 每个引擎有功率上限。装重甲会降速 |
| **吃水/离地** | 河船吃水 1.5m；轨道车需要铁轨或平直道 |

**三条互相牵制，改装就是取舍。**

### 3.2 改装地点

必须回改装台（铁砧、潮心港、铎港、河枢）。野外只能临时修理。

### 3.3 耐久

- 耐久归零 → 抛锚，需要拖回
- 每个部件独立计算耐久

## 五、驾驶

### 5.1 技能成长

| 技能 | 效果 |
|---|---|
| 驾驶 | 提升最高速度与操控 |
| 修理 | 提升野外修车效率 |
| 改装 | 解锁高级改装件 |

### 5.2 载具战斗

- 战车可边开边打
- 其他载具只能"撞"（伤害低，自己也受伤）
- 载具被毁时驾驶员受重伤（-50% 生命），不死

| 干燥荒野 | ✓ | ✕ | ✓ | ✓ | ✓ |
| 泥地 | ✓（慢） | ✕ | ✕ | ✕ | ✓ |
| 水（涨潮） | ✕ | ✓ | ✕ | ✕ | ✓ |
| 脊上道路 | ✓ | ✕ | ✓ | ✓（慢） | ✓ |

## 六、获取路径

**没有一辆载具是"买的"，都是"造出来的"。**

| 载具 | 路径 |
|---|---|
| 板车 | 自制，材料：木板 ×4 + 绳 ×2 |
| 河船 | 潮心港定制船体 → 装帆 → 装螺旋桨 |
| 轨道车 | 铁砧买底盘 → 收集引擎 → 自己装 |
| 战车 | 主线第 14 章 → 集齐 5 个部件 → 组装 |
| 飞行器 | 王家测绘局图纸 + 电池 + 机翼 → 需艾德帮忙 |

**战车的 5 个部件** 是最好的开放世界任务设计：玩家必须跑遍全图，每个部件都在一个"需要特定能力才能进入"的地方。

## 七、给程序的实现要点

1. 载具 = 一个容器 + 一组槽位 + 一个物理体
2. 槽位结构复用角色的 `slots` 数组，只是槽位 ID 不同
3. 重量/功率/耐久三值必须实时计算，不能缓存（改装是实时的）
4. 载具进出时，玩家角色"附生"到载具实体上（同一个移动控制器）
5. **v1 只做板车 + 河船**，轨道车与战车放 M4，飞行器放 M5
