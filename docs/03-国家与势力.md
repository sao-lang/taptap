## 二、七个政治实体详述

### 2.1 洛恩王国

**七百年农业帝国的黄昏，也是所有故事的底色。**

- **种族构成**：洛文人为主，各地有少数民族
- **政治**：老国王奥杜六世七十一岁，独子早逝，孙辈三个各怀心思。王室实际权力被城市财富稀释——税收的六成来自铁路沿线城市，而铁路是铎港的
- **军事**：壁卫营（旧）+ 铳兵营（新）+ 各领主私兵。总兵力纸面八万，能机动的不到两万
- **经济**：粮食出口大国。王都是大陆最大的消费市场
- **习俗**：王室加冕要在长河边"请河"；贵族联姻看重封地多过血缘
- **对干线**：**要**。路通则税通，王权能续五十年。但没钱出钱，只能出特许权

### 2.2 铎港自由市

**机工革命的心脏，大陆最年轻也最富的城市。**

- **种族构成**：洛文工人、诺尔技师、傀人劳工（四万台在册）
- **政治**：机工商会执政，会长即市长（现会长**多恩·铎**，铎三娘的第五代后人）。议会里工厂主、铁路公司、傀人制造商三足鼎立
- **军事**：护路军（商会出资，名义上护路，实际是商会陆军）
- **经济**：全大陆七成的机器产自铎港。辉票从这里发行
- **习俗**：点炉节全城熄灯再点灯；签合同比发誓庄重——"合同上有你的手印，比祠堂里有你的牌位管用"
- **对干线**：**最积极**。出钱的五成，也要路线走向的一半决定权

### 2.3 纹城

**咒术行会的自治城，全大陆的魔法都来自这里。**

- **种族构成**：纹人为主体，各族学徒常住
- **政治**：行会长老会（七位长老）。纹城不设市长——行会就是政府
- **军事**：没有军队。但有全大陆最强的**二十位过身级咒师**——没人想测试他们
- **经济**：学费、咒文授权费、静纹院的施舍收入。**纹城很穷**，但没人敢催债
- **习俗**：城内禁止炉烧（纹城全城没有一台机器，路灯是手引长明咒）；纹人葬礼叫"到家"
- **对干线**：**表面反对、内部分裂**。官方说火车震动惊断矿脉；年轻派咒师偷偷想要铁路（能去远方）

### 2.4 北境矿盟

**辉石的唯一产地，握着所有人的命脉却总觉得别人在偷它的钱。**

- **种族构成**：诺尔人为主，岩民聚居背阴谷
- **政治**：七座矿城的联盟议会 + 矿工兄弟会（工人权力实体，能动辄罢工）
- **军事**：矿卫队（准军事，打过硬仗——炉历 121 就是他们顶住了王国军）
- **经济**：辉石、铁。**定价权是矿盟最大的武器**，也是最大的心病
- **习俗**：下井敲三下头盔；矿难名单由岩民世代背诵
- **对干线**：**分裂**。商会派要运力（矿石运费降一半），兄弟会要工作（铁路修通矿上裁员）

### 2.5 森邦

**东部森林的氏族联盟，一个不设首都的国家。**

- **种族构成**：艾沃人氏族 + 少数洛文边民
- **政治**：十二氏族议事，驻地在十二个林村轮转
- **军事**：林哨（猎手武装，散兵游勇式，但森林里没人打得过他们）
- **经济**：木材、药材、毛皮。《林界约》限定王国采伐量，铁路枕木需求正在冲击这个约定
- **习俗**：砍树先问树；成年礼独居一月
- **对干线**：**反对声音最大、实力最弱**。干线东段要穿森林边缘——森邦要的是"绕路费"，嘴上说的是"树在疼"

### 2.6 牧盟

**西部草原的八部联盟，正在被铁路时代甩下的民族。**

- **种族构成**：哈兰人八部
- **政治**：长老议事，一年两会（春场、秋场）
- **军事**：全民皆兵的骑兵，但不会攻城
- **经济**：马、羊毛。**马匹生意被火车杀死了一半**——这是他们的切肤之痛
- **习俗**：奶茶三碗；马死要埋
- **对干线**：**怨恨最深**。铁路每通一里，马价就跌一分。八部里三部扬言"铁轨铺进草原就拔枕木"

### 2.7 白帆商盟

**南部海岸的港城联盟，海上的既得利益者。**

- **种族构成**：岬人为主，各族商人云集
- **政治**：港城联席商会（各港一票，潮心港双票）
- **军事**：商盟舰队（对海兽，不对人）
- **经济**：海运、盐、远岛货。**辉石船正在淘汰帆船**——商盟自己的内部革命
- **习俗**：船籍至上；女子当家
- **对干线**：**冷静旁观**。海路和铁路是竞争——但商盟算过账：干线通了，内陆货源反而更好收

| **矿工兄弟会** | 北境工人组织，能罢工 | 头领**布隆·三锤**（矿难遗孤） | 民生冲突线 |

## 四、八场正在进行的摩擦

**每场都按四段写：表面理由 / 真实算盘 / 玩家能做什么 / 不管会怎样。**

### 4.1 干线走向之争（主线核心）

- **表面**：东南段路线穿静谷，行会说震动惊断活矿脉，要改道
- **真实**：改道方案绕行纹城盟友的领地，多八十公里——**测绘数据被人动过手脚**。改道真正的受益方藏在图纸后面
- **玩家能做什么**：重测、查档、找证据、公开或私了
- **不管会怎样**：铁路照修，十年后矿脉减产，纹城势力衰一半

### 4.2 矿税之争

- **表面**：王国要提高辉石出口税，矿盟抗议
- **真实**：王国不是缺钱，是**故意逼矿盟涨价**——涨价的税基更大，还能嫁祸给"商会的囤积"
- **玩家**：卧底或调账（行贾线 / 测绘线的档案能力）
- **不管**：矿盟减产抗议，城市辉石涨价三成，傀人停摆

### 4.3 行会 vs 商会的百年账

- **表面**：行会要求立法"限制炉烧用石配额"
- **真实**：行会不是怕矿死，是**怕自己死**——城市每多一盏路灯，学咒术的孩子就少一个
- **玩家**：两边任务都接（行会敬老咒师，商会救火工厂）
- **不管**：法案流产，行会转入地下收徒，咒术质量失控

### 4.4 枕木特许权

- **表面**：铁路公司要向森邦"加购"三倍木材
- **真实**：加购是诱饵——铁路公司想要的是**伐木特许权**（永久），一旦到手，林界约作废
- **玩家**：帮森邦谈判（行贾线高阶），或帮公司做局
- **不管**：森邦内部分裂，主和氏族签了特许权，主战氏族开始烧林场

### 4.5 草原拔轨事件

- **表面**：牧盟三部威胁"铁轨进草原就拔枕木"
- **真实**：三部不是恨铁路，是恨**马价**。护路军若镇压，牧盟八部会空前团结——这是王国最怕的
- **玩家**：当调停人（需哈兰人或牧盟信任）
- **不管**：护路军与牧民第一次流血冲突，干线西段停工

### 4.6 王位暗流

- **表面**：老国王还在，无人谈继承
- **真实**：三个王孙各有一派。**干线的特许权是三方共同争夺的第一块肉**——谁签下来，谁的派系就有了钱
- **玩家**：主线后期不可避免地被卷入
- **不管**：不受伤的是王都，受伤的是所有在场的人

### 4.7 傀人诉讼案

- **表面**：一台战地傀要求"存档权"（把自己的人格数据存进静纹院）
- **真实**：商会怕的不是一台傀，是**四万台傀的先例**。静纹院怕的不是商会，是自己成了"傀人的教会"
- **玩家**：找证据（傀人第九批的秘密）、当证人
- **不管**：案件拖延，傀人开始自发"存档"自己的记忆（用歪门方法，出事故）

### 4.8 护路军扩权

- **表面**：护路军要求"铁路沿线百里执法权"
- **真实**：督军铁澜要的不是权，是**合法性**——佣兵出身的他知道军队没有名分迟早被清算
- **玩家**：护路军任务线的最终选择（给他名分 / 揭他旧案）
- **不管**：护路军变成商会的私兵，地方领主开始自建武装

## 七、经济体系

### 7.1 货币

| 货币 | 是什么 | 谁在用 |
|---|---|---|
| **角子**（银币） | 一天饭钱的基本单位 | 全大陆 |
| **辉票** | 机工商会发行的纸币，可兑辉石份额 | 城市与商人 |
| **矿筹** | 矿盟内部的记账筹码 | 北境 |
| **以物易物** | 粮食、辉石本身 | 乡村、牧盟、森邦 |

**三角关系**：辉票的信用靠商会，角子的信用靠王室，矿筹靠矿盟。**三家的汇率就是三家的政治。**

### 7.2 一条产业链（所有经营玩法的骨架）

```
矿盟挖辉石 → 商会买（辉票）→ 工厂烧（机器/傀人/灯）
        ↘ 行会买（现金）→ 手引（咒术）
        ↘ 乡村买（小额）→ 采暖、炉灶

森林伐木 → 枕木/建材 → 铁路扩张 → 运费下降 → 矿石更便宜
草原养马 → 马价被火车压 → 牧盟怨气 → (摩擦 4.5)
农场种粮 → 城市供给 → 工人吃饭 → 工厂开工
```

**玩家经营的农场/作坊/商队，全部挂在这条链上的某一环。** 环上任何一环的摩擦（第四章），都会传导到玩家的生意上——这是"经营"和"世界观"咬合的方式。

### 7.3 物价基准（角子）

| 品类 | 价格 | 备注 |
|---|---|---|
| 一天饭钱（平民） | 1 | 基准 |
| 一晚旅店 | 2 | 乡下 1，铎港 4 |
| 一枚标准辉石（民用级） | 30 | 乡村术士一个月收入 |
| 一支军用辉石铳 | 400 | 士兵两年军饷 |
| 一台傀人 | 2000 | 工厂两年的利润 |
| 一节火车货运车厢（单程） | 350 | 干线通之前的价格 |
| 一亩河谷田（年租） | 8 | 种田玩法的地基 |
