# 09 · 宠物与伙伴

> 《定线人》设定集 第八册
> 16 种可驯化生物（四阶进化）、30 件宠物装备、15 名可招募伙伴。

---

## 一、宠物 ≠ 伙伴

| | 宠物 | 伙伴 |
|---|---|---|
| 本质 | 低等生物，有特殊器官 | 智慧生物，与玩家同级 |
| 来源 | 野外蛋/幼体 | 剧情招募 |
| 装备 | 宠物专属 4 槽 | **与玩家共用装备池** |
| 数量 | 最多 2 只出战 | 最多 1 名出战 |
| 死亡 | **永久死亡** | 重伤撤退 |
| 说话 | 不能 | 能 |
| 进化 | 四阶 | 不能 |

**宠物是用来"失去"的。** 这是刻意的——它让每场战斗都有真实的重量。

---

## 二、驯化

| 方式 | 说明 | 成功率 |
|---|---|---|
| 偷蛋 | 从巢里拿走，母兽会追 | 60% |
| 喂食 | 连续喂 3 次同一种食物 | 40% |
| 压制 | 打残不杀，用绳索束缚 | 30% |
| 模仿 | 学它的叫声 | 25% |
| 共生 | 被它寄生，不驱除 | 15%（无法解除） |

失败不会死，但失去这只生物，且该物种对你的驯化率永久 -5%。

---

## 三、进化

```
胚（蛋）→ 幼体 → 成体 → 极体
```

| 进化 | 材料 |
|---|---|
| 幼体 → 成体 | 对应**晶核**（力/体/敏/智/感/魔石） |
| 成体 → 极体 | 对应**畸晶 + 该物种的"母体器官"** |

喂下材料的瞬间，宠物会抽搐、脱壳、长出新器官。**过程不可取消。**

部分物种有**分支进化**：喂力晶/体晶走防御形态，喂敏晶/魔石走攻击形态。不可逆。

## 六、15 名可招募伙伴

### 01 · 丽薇

**洛文人 · 女 · 27 岁 · 拾遗 · 拾遗者**

**外形**：短发，脸上有几颗雀斑。左眉上方一道旧疤，是小时候被弩箭擦的。走路几乎没有声音。

**来历**：王都下城区的猎户女儿。十六岁那年她父亲欠了地租，地被收走。她跟着旧矿坑猎人队进了旧矿坑，靠当斥候活下来。行会里公认"最会活着回来"的人。

**性格**：谨慎、话少、习惯先看退路。笑得快，收得也快。

**执念**：把父亲那块地买回来。她存了十一年钱。

**口头禅**：「先看退路。」

**战斗**：探路（显示前方 50 米）／警戒（免疫偷袭）／掩护射击（替你挡一次远程）

**招募**：主线第 3 章 · 河枢营地

**好感 5**：她把存钱的布袋给你看。里面是一把钥匙——地已经买回来了，她没敢回去看。

## 七、伙伴系统规则

### 7.1 装备共用

伙伴使用玩家的装备池。

> 你打到一把「裂甲·晶蚀」的刀。
> 给卡尔文，他能顶住更多伤害。
> 给自己，你能打得更快。
> **你只能选一个。**

这是全作最重要的资源分配设计——它让每件掉落都有意义。

### 7.2 伙伴不会死

重伤撤退，需要治疗（消耗角子）。不会永久死亡——"失去伙伴"惩罚太重，会让玩家读档。

但宠物会。

### 7.3 好感度

| 级别 | 解锁 | 怎么升 |
|---|---|---|
| 1 | 会主动打招呼 | 初次招募 |
| 2 | 会说自己的事 | 一起战斗 5 次 |
| 3 | 会给私人委托 | 完成一个相关支线 |
| 4 | 战斗中会主动帮你 | 好感 3 后一起战斗 10 次 |
| 5 | 会给"遗物" | 完成个人结局 |

**送礼只能到 2 级。** 3 级以后必须靠"在他需要的时候出现"。

### 7.4 出战限制

同时只能带 1 名伙伴 + 2 只宠物。

- 带坦克 → 自己能输出，缺治疗
- 带治疗 → 续航强，打不动
- 带宠物 → 数量优势，但宠物会死
