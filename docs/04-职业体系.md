# 04 · 职业体系

> 《定线人》设定集 第四册
> **20 条职业线，每条线三阶、三个名字，进阶即换名换能力。**
> 战斗线 10 · 科技线 4 · 探索线 3 · 生活线 3，另设 7 个专属职业（主角 1、NPC 6）。
> **命名原则：不用"弓手、法师、战士"这类通行词。每个名字必须在这个世界的军队、行会、工厂或村落里找得到出处。**

---

## 一、总则

### 1.1 职业从哪来

这个世界的职业不是"天赋"，是**活法**——每条线都长在一个具体的社会位置上：

- 王国要有人站成一排不后退 → 有了壁卫线
- 工厂要有人修机器 → 有了机工线
- 矿工下坑要有人打头灯 → 有了拾遗线
- 火车上要卖饭 → 有了庖馔线

**没有一条线是"游戏需要一个职业"才存在的。**

### 1.2 三阶结构

```
一阶（入门）→ 二阶（立身）→ 三阶（成名）
```

| 阶 | 含义 | 转职条件 |
|---|---|---|
| 一阶 | 你入行了 | 开局即选（或 NPC 出场自带） |
| 二阶 | 你能靠它吃饭了 | 对应属性达 B + 完成转职任务 |
| 三阶 | 你在这行有了名字 | 对应属性达 A + 传承任务 + 一件职业信物 |

**转职任务不是打怪，是"证明你懂这行"**——例如壁卫线的二阶任务是"掩护三个平民撤出兽群，且他们不受伤"。

### 1.3 一人几条线

- **战斗 / 科技 / 探索线：同时只能持有一条**（这是你的"本行"）
- **生活线：另算，最多兼两条**（种田的也可以做饭，但做不全）
- 专属职业不占线位（主角的测程线是身份，不是本行）

### 1.4 与装备联动

每条线限定武器与护甲范围，范围内吃加成，范围外可用但有惩罚：

| 线 | 主用武器 | 护甲 | 加成方向 |
|---|---|---|---|
| 壁卫 | 单手剑、盾、长枪 | 重甲 | 格挡、坚守 |
| 锋决 | 刀、短剑、匕首 | 轻甲 | 攻速、连击 |
| 弓戍 | 弓、弩 | 皮甲 | 射程、精准 |
| 枪骑 | 长枪、骑枪 | 中甲 | 冲锋、马战 |
| 咒锋 | 单手剑 + 副手辉石 | 中甲 | 咒剑双修 |
| 引咒 | 法杖、辉石、咒书 | 布袍 | 咒文强度 |
| 守纹 | 杖、锤、灯 | 布袍/皮甲 | 治疗、抗纹 |
| 影行 | 匕首、短弩 | 无甲偏好 | 潜行、爆发 |
| 驭兽 | 长鞭、短弓 | 皮甲 | 宠物指挥 |
| 铳械 | 辉石铳 | 中甲 | 远程爆发 |
| 机工 | 扳钳、工具枪 | 工装 | 装置、修理 |
| 傀操 | 命令节杖 | 布袍 | 傀人操纵 |
| 驱甲 | 驱甲臂配重、破城锤 | 驱甲（特殊） | 重击、破障 |
| 锻铸 | 战锤、锻斧 | 围裙甲 | 打造、战时强化 |
| 识途 | 短棍、马刀 | 皮甲 | 地形、机动 |
| 拾遗 | 灯杖、捕网 | 皮甲 | 探索、陷阱 |
| 观星 | 星盘、短杖 | 布袍 | 预判、导航 |
| 垦植 | 锄、草叉 | 布袍 | 农事 |
| 庖馔 | 菜刀、餐叉 | 布袍 | 烹饪 |
| 行贾 | 账本、短剑 | 布袍 | 交易 |

**跨线用武器可以，但吃不到加成且有惩罚**（如引咒穿金属甲，咒文消耗 +50%——纹人条目里解释过原因）。

### 1.5 与种族联动

见 02 册第五节相性表。补充两条硬规则：

- **傀人无法走守纹线**（治疗咒术对它无效，学了也用不了）
- **纹人无法走驱甲线**（驱甲贴身金属，与纹人身躯冲突）

## 二、战斗线（10 条）

### 2.1 壁卫线：执盾人 → 壁卫 → 不退者

**起源**：旧历 133 年壁卫营。平原无险可守，王国靠人站成排。三百年的军制，"不退"两个字刻在每一面盾的背面。

**社会位置**：最受尊敬的行伍。退役壁卫是各村争抢的村警、教头。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **执盾人** | 盾墙：格挡 +15%，格挡成功回复少量士气 |
| 二阶 | **壁卫** | 定线：原地不动时全防御 +40%；"掩护"指令（替队友承伤） |
| 三阶 | **不退者** | 壁立：每战一次，8 秒内全队不死（生命最低锁 1），期间你不能移动或攻击 |

> 「站住。别动。就这一件事。」

### 2.2 锋决线：巷刃 → 双锋客 → 断影

**起源**：城市街巷。镖师、角斗场、下城区的恩怨——一把刀太慢的地方，人们学会了第二把。

**社会位置**：灰色地带。上不了正席，但有钱人夜里都睡得着，因为巷刃在巡街。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **巷刃** | 双持：副手持刀伤害 60% |
| 二阶 | **双锋客** | 连影：三连击，第三击必暴 |
| 三阶 | **断影** | 一闪：0.5 秒内位移到目标背后并全额暴击（每战两次） |

> 「第一刀问路。第二刀办事。」

### 2.3 弓戍线：林哨 → 风哨 → 落羽

**起源**：艾沃氏族的猎手传统 + 王国边军哨所。猎手编入军制后，"看住林子"成了兵役。

**社会位置**：森邦里是本事，王国军里是"辅兵"。城里人管他们叫"守林的"。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **林哨** | 稳弦：静止时精准 +25% |
| 二阶 | **风哨** | 逐风箭：射程 +30%，命中减速 |
| 三阶 | **落羽** | 群落：一箭射落接空中目标（可打飞行怪、接坠落的队友/宠物） |

> 「等它抬头。」

### 2.4 枪骑线：突骑 → 贯阵骑 → 破营者

**起源**：哈兰牧盟的骑手被王国收编为**贯阵营**（炉历 103 军改）。草原的马，王国的心。

**社会位置**：牧盟青年出人头地的正路，也是牧盟老人叹气的路。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **突骑** | 骑枪冲锋：速度越快伤害越高 |
| 二阶 | **贯阵骑** | 贯阵：冲锋可穿透两个目标 |
| 三阶 | **破营者** | 破营：下马一击，对工事、大门、防御阵 ×3 伤害（攻城/破门玩法入口） |

> 「马快不是本事。知道什么时候松缰绳才是。」

### 2.5 咒锋线：附锋者 → 咒刃 → 灼锋

**起源**：军中咒师太脆，配了贴身护卫。护卫看了三十年咒文，有人偷偷学会了把咒**附在刀上**。

**社会位置**：行会与军队的混血儿——两边都认，两边都不完全认。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **附锋者** | 附锋：给武器附加一阶咒（火、风、光），持续 30 秒 |
| 二阶 | **咒刃** | 咒锋同源：攻击与施咒共享冷却（互不等待） |
| 三阶 | **灼锋** | 满引：把两阶咒一次附满武器，爆发一刀——**石纹 +1 阶**（永久，不可逆） |

> 「他们念咒要十息。我这一刀，也是十息。」

### 2.6 引咒线：引咒人 → 咒师 → 织纹者

**起源**：纹城。手引辉石的系统化学问，从旧历 740 年的行会第一课传到今天。

**社会位置**：又敬又怕。军队的最爱，旅店的加钱对象。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **引咒人** | 一阶咒文（火/风/光/力） |
| 二阶 | **咒师** | 二阶咒文；可引他人石纹代偿（危险技巧） |
| 三阶 | **织纹者** | 三阶咒文；**纹路管理**：可把已爬升的石纹"织"成稳定态（停止恶化，代价是永久损失一阶咒文上限） |

> 「咒是纹路的语言。你念得越流利，纹听得越清楚。」

### 2.7 守纹线：执灯医 → 守纹师 → 静纹师

**起源**：静纹院。收容纹满者的地方，也需要有人**延缓纹满**——守纹的医术由此而来。

**社会位置**：教会与行会之间。伤兵营、矿难现场、纹满者病榻——哪里疼哪里有他们。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **执灯医** | 暖引：治疗（非咒术，是"引导能量缓释"），无石纹代价 |
| 二阶 | **守纹师** | 守纹：减缓队友石纹爬升 50%；解毒、镇痛 |
| 三阶 | **静纹师** | 静纹领域：8 秒范围内敌人石纹类能力失效（对咒师是沉默，对石纹怪是瘫痪） |

> 「我不能把纹退回去。我只能陪你走慢一点。」

### 2.8 影行线：檐行者 → 无声者 → 夜隙

**起源**：城市屋檐。追债的、送密信的、查账的——白天不属于他们。

**社会位置**：厢行的外围。没人承认认识你，但事都办成了。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **檐行者** | 潜行：暗处自动隐匿 |
| 二阶 | **无声者** | 无声步：移动不破隐；偷窃、开锁检定 +40% |
| 三阶 | **夜隙** | 过隙：从任何"守卫状态"中瞬间脱出（被包围、被锁定、被抓——每日三次） |

> 「别找门。找门框和门之间那道缝。」

### 2.9 驭兽线：围手 → 唤兽人 → 百兽引

**起源**：草原围猎。八部合围，人喊马嘶——领头喊的那个人，就是围手。

**社会位置**：牧盟的荣耀职业。城市人叫他们"耍兽的"，直到自己的坐骑只听唤兽人的话。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **围手** | 驯兽：可驯化低阶生物；同时指挥 1 只 |
| 二阶 | **唤兽人** | 唤群：指挥 2 只；宠物继承你的暴击率 |
| 三阶 | **百兽引** | 引百兽：指挥 3 只；**进化引导**——由你亲手执行的宠物进化，成功率 +30% |

> 「兽不需要听懂你。它只需要信你。」

### 2.10 铳械线：点铳手 → 排铳兵 → 贯铁者

**起源**：炉历 103 军改。练一个铳兵二十天，养一个咒师十年——账算得清的军队都换了铳。

**社会位置**：新军队的骨干、护路军的巡逻配置、猎人的转型方向。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **点铳手** | 装填：装填速度 +25% |
| 二阶 | **排铳兵** | 排射：与相邻队友齐射，破甲 +50% |
| 三阶 | **贯铁者** | 贯铁弹：一发射穿三人 + 装甲（每战一次，需要特制弹——锻铸线可造） |

> 「咒师十年，我二十天。你觉得将军会心疼谁？」

## 三、科技线（4 条）

### 3.1 机工线：工学徒 → 机师 → 驱机师

**起源**：铎三娘的锅炉房。第一台辉石炉的学徒们成了第一代机师，他们的学徒遍布大陆。

**社会位置**：城市新贵。工厂的骨头、铁路的血液。机师失业率全大陆最低。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **工学徒** | 修理：修复机械类目标（含傀人队友） |
| 二阶 | **机师** | 设机：战斗中放置哨戒铳塔、障壁；改装载具（改装槽 +1） |
| 三阶 | **驱机师** | 过载驱机：给任意机器（含载具、傀人、铳塔）过载 ×2 输出 10 秒，之后必须大修 |

> 「机器不会骗你。它坏了就是坏了——人不一样。」

### 3.2 傀操线：牵傀师 → 傀师 → 百傀师

**起源**：傀人出厂需要"牵"——用节杖引导傀人行为的人。最初是工头，后来成了战斗编制。

**社会位置**：军队的新兵种、工厂的红人、伦理辩论的风暴眼。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **牵傀师** | 牵一：指挥一台战斗傀（与伙伴/宠物共存的独立编制） |
| 二阶 | **傀师** | 双牵：指挥两台；傀人可装备宠物装备池的"傀用变体" |
| 三阶 | **百傀师** | 傀阵：战斗中召唤一次性傀群（六台，30 秒）——**"傀人诉讼案"的法庭每传唤一次百傀师，旁听席都挤满** |

> 「律法说它们是我的财产。我的杖说它们是我的弟兄。两个都对，这才是麻烦。」

### 3.3 驱甲线：着甲机兵 → 驱甲兵 → 铁肤者

**起源**：铎港船坞的源力吊甲——工人卸货用的外骨骼。私掠队第一个把它改装成了战甲。

**社会位置**：新兴兵种。一台驱甲 = 五个壁卫的防御 + 三分之一的机动。贵，但打仗的人都在订。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **着甲机兵** | 驱甲负挂：可穿驱甲（其他线穿会大幅减速）；力量检定按机器算 |
| 二阶 | **驱甲兵** | 铁冲：驱甲冲刺，撞开障碍与小体型敌人 |
| 三阶 | **铁肤者** | 卸甲：主动脱离驱甲获得 30 秒全额灵活（人甲双形态切换，战场跳位） |

> 「穿进去的时候你是铁。脱出来的时候，你还是你——这句话是我们自己对自己说的。」

### 3.4 锻铸线：炉徒 → 锻师 → 宗匠

**起源**：诺尔矿城的锻炉。矿工兄弟会的看家手艺，战时即是军械厂。

**社会位置**：矿盟的顶梁柱。一柄好刀上会打上锻师的印——那个印就是信用。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **炉徒** | 锻修：打造与修理武器（+词条重铸） |
| 二阶 | **锻师** | 炉火纯青：打造成功率 +20%；战时强化（当场给队友武器加一次词条） |
| 三阶 | **宗匠** | 铸魂：为神器级装备重铸词条上限；**职业信物：自铸的印章（所有打造物永久署名，流通市场溢价 15%）** |

> 「我的印在剑上。剑去哪，我的手艺就去哪。」

## 四、探索线（3 条）

### 4.1 识途线：识途者 → 引路人 → 开道者

**起源**：商路。走通一条新路的向导，能吃十年的路费——"识途"是行话，也是头衔。

**社会位置**：商队的命根子、军队的斥候、干线测绘队的地陪。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **识途者** | 认路：小地图范围 +50%；迷路状态免疫 |
| 二阶 | **引路人** | 引队：全队移动 +15%；带队穿越危险地形（沼泽、矿区塌陷带）无伤 |
| 三阶 | **开道者** | 开道：在无路地形上"踩"出一条路（全队通行，地图永久记录——**测绘玩法的服务端入口**） |

> 「没有路。只有我走过的地方。」

### 4.2 拾遗线：提灯人 → 拾遗者 → 深行家

**起源**：旧矿坑。矿工丢了家伙什要人去捡，后来捡东西的人发现坑里值钱的比丢的多。

**社会位置**：拾遗会成员。游走在矿盟、行会和厢行之间的灰色职业——合法地拿，不合法地卖。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **提灯人** | 探照：黑暗视野 +30 米；陷阱感知 |
| 二阶 | **拾遗者** | 拾遗：地牢内标记可回收物（材料、遗物、旧装备）；陷阱拆除 |
| 三阶 | **深行家** | 深行：进入"未探明层"（每座旧矿坑最深处，风险 ×3 收益 ×3 的区域，仅深行家能带队） |

> 「矿工往下挖是为了矿。我们往下走，是为了矿工没带回来的东西。」

### 4.3 观星线：观星人 → 读星者 → 司星官

**起源**：商盟导航。远海船靠银盘和光帘认路，船上的导航员是"观星"的。后来他们发现，天象还能**预判天气与兽潮**。

**社会位置**：商盟的贵重雇员、军队的气象官、乡下的"算天的人"。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **观星人** | 夜航：夜间与海上的方向感；明日天气预报（精准 24 小时） |
| 二阶 | **读星者** | 读天：未来三天天气；战斗中预读敌人下一轮动作（显示意图） |
| 三阶 | **司星官** | 天时：预知一场**天象事件**（兽潮南下、暴雨封河、矿脉异动）的准确时间——**全队可提前布置（种田、护田、伏击、撤资）** |

> 「星星不说话。星星只是先看见了。」

## 五、生活线（3 条）

**生活线不吃"一条本行"的限制**（最多兼两条），且**每阶都解锁经营玩法的实质内容。**

### 5.1 垦植线：垦夫 → 田把式 → 沃野师

**起源**：河谷。从旧历 0 年争水打到统一的那批人，后代如今在垄上。

**社会位置**：王国的根基，也是课税的对象。田把式是十里八乡的农事权威。

| 阶 | 名字 | 解锁 |
|---|---|---|
| 一阶 | **垦夫** | 开田：一块可耕作田（播种、浇水、除虫小游戏化处理） |
| 二阶 | **田把式** | 轮作：多块田 + 轮作系统（连作减产、轮作增产）；引渠灌溉 |
| 三阶 | **沃野师** | 沃野：**改造田土**（蓝草田、药圃、谷仓升级）；收成与当地物价联动（行贾线接口） |

> 「庄稼不看你辛苦。庄稼看你对不对时候。」

### 5.2 庖馔线：灶下工 → 掌勺 → 五味师

**起源**：跑长途的火头军。后来火车站的餐车把这行带进了城市。

**社会位置**：火头军出身是荣耀，餐车掌勺是时髦。五味师是全大陆抢人的存在。

| 阶 | 名字 | 解锁 |
|---|---|---|
| 一阶 | **灶下工** | 生炊：基础料理（恢复类，效果 = 原料之和） |
| 二阶 | **掌勺** | 配菜：料理词条化（两原料组合出增益，如"夜目汤"= 夜间感知 +2） |
| 三阶 | **五味师** | 五味：**宴席料理**（全队增益持续一整次探索）+ 职业信物"五味盒"（野外便携灶台） |

> 「地里长的、海里游的、你打的，到我锅里才变成东西。」

### 5.3 行贾线：货郎 → 坐贾 → 巨贾

**起源**：官道。肩挑货担走村串巷是第一代行贾；如今他们坐进了火车车厢。

**社会位置**：王国管他们叫商税，乡下人管他们叫老板，厢行管他们叫同行。

| 阶 | 名字 | 解锁 |
|---|---|---|
| 一阶 | **货郎** | 摆摊：村镇级摆摊（收购差价 ±10%） |
| 二阶 | **坐贾** | 商号：城镇开铺（常驻买卖 + 两名伙计 NPC） |
| 三阶 | **巨贾** | 商路：**组建商队**（载具接口——商队沿铁路/官道自动跑商，收益与势力摩擦联动） |

> 「低买高卖是货郎。让路替你跑货，才是巨贾。」

## 六、专属职业（7 个）

**专属职业不是转职来的，是身份——只有特定的人能持有。**

### 6.1 【主角专属】测程线：测绘学徒 → 量地官 → 定线人

**来历**：王家测绘局的职级序列。干线工程启动，局里把老、弱、闲散人手全派出去测绘——你就是被派出去的那个（主线入口）。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **测绘学徒** | 测杆：探索地图记录 +30%；发现隐藏路径 |
| 二阶 | **量地官** | 量地：任意两点间生成"拟建路线"（预览未来铁路走向——剧情工具+快速旅行规划） |
| 三阶 | **定线人** | 定线：**主线终局权限**——干线东段的最终走向，由你的测绘报告决定（三结局的技术入口） |

**为什么只有主角**：全局只有一人能走到"定线人"——因为走到三阶需要的东西（那段被造过假的原始数据）在主角手里。

> 「局长说：地图是刀。画线的人决定谁的田被切开。」

### 6.2 【NPC 专属】织印人 · 宰相府密探（一人）

只属于王都宰相的暗线职位。伪造印信、文书、测绘数据的黑手——**主线数据造假的源头**就是他。玩家在三阶支线"纸上的河"里第一次见到他的作品（一份完美的假地形图）。

**能力**（敌方）：伪造一切官方文件；可替换 NPC 身份（剧情杀）。

### 6.3 【NPC 专属】守矿使 · 矿盟独一职位（一人）

矿盟对辉石脉的**首席判断官**——她说这条脉能采就采，说不能就没人敢下镐。现任守矿使**巩铁婆**（诺尔人，八十岁，矿难遗孤的养母）。

**剧情位置**：静谷活矿脉的判定权在她手里——她是主线两边都想争取的人。她的判断方式是"贴脉听三天"，没人知道她在听什么。

### 6.4 【NPC 专属】静纹使 · 静纹院首座（一人）

灰姑的职位。**纹满三年还没走完的人**——历史上没有一个静纹使者活到卸任。她管理静纹院，也是全大陆唯一能"读石纹"的人（摸你的手臂，说出你引过多少咒、哪一道是你最舍不得的）。

**剧情位置**：咒锋线、引咒线的三阶传承任务都经过她；傀人诉讼案的关键证人。

### 6.5 【NPC 专属】护路督军 · 护路军统帅（一人）

铁澜的职位。佣兵出身、矿盟战争的老兵、商会最锋利的一把刀。他不是反派——**他是在"没有名分的军队"里想活到退役的聪明人**。

**剧情位置**：护路军任务线的终局选择给他"名分"还是"揭旧案"；草原拔轨事件的镇压命令由他签发。

### 6.6 【NPC 专属】司秤人 · 拾遗会会首（一人）

秤婆的职位。拾遗会的规矩：会首必须能**"称出来历"**——一件遗物放上天平，她说出它从哪来（服务端设定上是鉴定系统的人格化身）。传位方式：秤倾斜两次，传给让她看走眼的人。

**剧情位置**：神器鉴定的入口 NPC；深行家转职的最后试炼由她出题。

### 6.7 【NPC 专属·伙伴】第七型 · 诺克的原型编号

傀人伙伴**诺克**的专属职业。它是炉历 90 年第一台傀的原型机（编号第七），第九批之前、又"怕疼"之后的**孤例**。它自己不知道自己是什么。

**能力**：独有的"存档"机制（每章可存一次"人格快照"——死亡时从快照恢复，但丢失快照之后的记忆，与傀人诉讼案的"存档权"直接呼应）。

**剧情位置**：傀人诉讼案的活证据；它的选择（公开编号 / 保持沉默）是傀人线的终局。
