# 04 · 圣职体系

> 《定线人》设定集 第四册
> **20 条圣职线，每条线三段位阶、三个称号，进阶即换名换能力。**
> 战斗线 10 · 科技线 4 · 探索线 3 · 生活线 3，另设 7 个专属职业（主角 1、NPC 6）。
> **命名法典（见 00A 第九节）**：取西方古典魔幻的位阶制——**侍从阶（Squire / Apprentice）→ 誓约阶（Knight / Adept / Ranger）→ 冠冕阶（Warden / Archmage / Lord / Grandmaster）**。一阶写"入门者持什么"，二阶写"这一道的核心技艺"，三阶写"这一道的极致"。**禁止用杂役活计命名**（不写马厩徒、擦铳徒、灶下徒），词根只取自十四柱的尊号、神器圣名与神壤。**冠冕是职称，不是神选**——万神殿教团的原意是"在这一道上守到被同行记住的人"。
> **每条线固定九项**：称号三阶 / 能力 / 技能表（6 技）/ 可装备武器 / 防具 / 属性成长 / 词条亲和 / 晋升条件 / 侧重方向联动。

## 一、总则

### 1.1 圣职从哪来

这个世界的职业不是"天赋"，是**活法**；圣职也不是神赐，是万神殿教团给这些活法**登记了一个归属**。每条线都长在一个具体的社会位置上：

- 王国要有人站成一排不后退 → 有了壁卫线（登记在忒拉蒙）
- 工厂要有人修机器 → 有了机工线（登记在希莱昂）
- 矿工下坑要有人打头灯 → 有了拾遗线（登记在熄光者）
- 火车上要卖饭 → 有了庖馔线（登记在薇兰蒂）

**没有一条线是"游戏需要一个职业"才存在的，也没有一条线是"神指派了一个职业"才存在的。** 登记只说明这行活儿像哪一柱的性，不说明神在管它。

### 1.2 三段位阶

```
侍从阶（持什么入门）→ 誓约阶（这一道的技艺）→ 冠冕阶（这一道的极致）
```

| 阶 | 位阶 | 西式称谓 | 转职条件 |
|---|---|---|---|
| 一阶 | **侍从阶** | Squire / Apprentice / Acolyte | 开局即选（或 NPC 出场自带） |
| 二阶 | **誓约阶** | Knight / Adept / Ranger / Artificer | 对应属性达 B + 完成转职任务 |
| 三阶 | **冠冕阶** | Warden / Archmage / Lord / Grandmaster | 对应属性达 A + 传承任务 + 一件职业信物 |

**转职任务不是打怪，是"证明你懂这行"**——例如壁卫线的二阶任务是"掩护三个平民撤出兽群，且他们不受伤"。三阶的传承任务必须在该神的**柱日**于对应神殿/神壤完成，仪式内容仍是交一件活儿，不是祈祷、不是受谕（缄默律）。

### 1.2·补 每条线的九项字段（本次新增）

每条圣职线必须写满下列九项，缺一项视为未完成。技能表统一 6 技（`Ⅰ/Ⅱ` 为侍从阶、`Ⅲ/Ⅳ` 为誓约阶、`Ⅴ/Ⅵ` 为冠冕阶），数值口径沿用 07 册。

| 字段 | 写什么 | 与谁咬合 |
|---|---|---|
| **能力** | 三阶各一条核心被动/主动 | 三阶称号 |
| **技能表** | 6 个具名技能：类型 / 效果 / 冷却 / 消耗 | 07 册词条数值、13 册 UI 技能栏 |
| **可装备武器** | 主用 / 可用 / **禁用**三类，精确到 07 册 20 类武器 | 00A 3.3 硬规则、07 册 |
| **防具** | 可用甲型 + 越界惩罚 | 07 册 11 类防具 |
| **属性成长** | 每阶主属性阈值 + 升阶永久加成 | 02 册六项属性 |
| **词条亲和** | 该线易触发的前缀/后缀 | 07 册 24 前缀 + 3 柱徽 |
| **晋升条件** | 侍从→誓约→冠冕的具体任务 | 06 册任务卡 |
| **侧重方向联动** | 该线所属修向、升级解锁什么 | 00A 3.3 / 02 册 |

### 1.3 一人几条线

- **战斗 / 科技 / 探索线：同时只能持有一条**（这是你的"本行"）
- **生活线：另算，最多兼两条**（种田的也可以做饭，但做不全）
- 专属职业不占线位（主角的测程线是身份，不是本行）
- **奉神不占线位、不给加成**：它是登记信息，显示在人物卡的角标上（神徽色点 + 一字），不是 buff

### 1.5 与十四裔联动

见 02 册第六节相性表（14 裔 × 20 线）。补充四条硬规则：

- **伊格尼人无法走守纹线**（治疗咒术对它无效，学了也用不了）
- **俄涅人无法走驱甲线**（驱甲贴身金属，与俄涅人身躯冲突）
- **诺克提人的伙伴好感上限锁死**（神禁，任何道具不能突破）
- **伏尔提人不能做静止类转职任务、艾欧恩人不能做抢先类转职任务**（两者需在柱日以替代任务完成，规矩不变）

### 1.6 每条线的侧重方向（联合设计 · 一族一向的投影）

> 20 条线的侧重方向，直接取自该线奉神之裔的修向（00A 3.3）。**玩法的"升级"就是这一向的成长**：三阶解锁的往往是该向质变（异化解冻一个器官、契约开启宠物进化、咒术拿到高阶法杖）。改职业线要回头看 00A 3.3.2 的整张绑定表。

| 线 | 奉神 | 侧重方向 | 三阶质变 |

| 弓戍 | 风 | 骑驭（坐骑） | 群落射落空中目标/接宠物 |
| 枪骑 | 风 | 骑驭（坐骑） | 破营攻城，开启马战 |
| 咒锋 | 火 | 重铠（热兵过载） | 引焰满刃，石纹 +1 |
| 引咒 | 能量 | 咒术（魔法） | 纹路管理，三阶咒文 |
| 守纹 | 时间 | 辰序（延缓预知） | 静纹领域 |
| 影行 | 暗 | 潜行（潜隐潜行） | 过隙脱出 |

**两条跨系统硬规则（本册继承 00A 3.3.3，落地到职业）**：

1. **魔道武器限定**：走「咒术（引咒线）」「显影（拾遗线）」两条术道的职业，**只能装备 法杖 / 魔法书 / 触媒 / 晶刃** 四类武器；其余线拿这四类则法术槽不可用、对应词条不触发。水、时间二柱不授兵器，故涅瑞德人、艾欧恩人二裔玩家无近战武器类，只有塑甲/面具/时节后缀（07 册定形神表既有设定，在此统一纳入）。
2. **召唤/骑乘限定**：全大陆**只有「契约（驭兽线）」「骑驭（枪骑线、弓戍线）」能召/骑**——契约唤**契兽**（09 册宠物，与主人同进化），骑驭骑**坐骑**（独立坐骑系统）。其余各线**完全不能召唤宠物、不能骑乘**；09 册 30 件宠物装备只对这两类线生效，契兽「唱名立契」也只在这两类线开启。

## 二、战斗线（10 条）

### 2.1 壁卫线：铁盾扈从 → 磐石骑士 → **不动守望者**

**奉神**：忒拉蒙（铸形者·土）／镇守 ｜ **冠冕词根**：忒拉蒙 · 镇守（镇守城垣，磐世之王）
**起源**：旧历 133 年壁卫营。平原无险可守，王国靠人站成排。三百年的军制，"不退"两个字刻在每一面盾的背面。**圣职登记在忒拉蒙，因为这一行的全部本事就是"磐世之王"**。

**社会位置**：最受尊敬的行伍。退役壁卫是各村争抢的村警、教头。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **铁盾扈从** | 盾墙：格挡 +15%，格挡成功回复少量士气 |
| 二阶 | **磐石骑士** | 定线：原地不动时全防御 +40%；"掩护"指令（替队友承伤） |
| 三阶 | **不动守望者** | 壁立：每战一次，8 秒内全队不死（生命最低锁 1），期间你不能移动或攻击 |

> 「站住。别动。就这一件事。」

**技能表**（6 技）

| 技 | 名 | 类型 | 效果 | 冷却 / 消耗 |
|---|---|---|---|---|
| Ⅰ | **盾墙** | 主动 | 格挡 +15%，格挡成功回士气 4 | 常驻 |
| Ⅱ | **踏桩** | 被动 | 原地不动 2s 后减伤 +8%，移动即失效 | 常驻 |
| Ⅲ | **掩护** | 主动 | 替一名队友承伤 6s，期间其受击转你 | 18s |
| Ⅳ | **定线** | 被动 | 原地不动时全防御 +40% | 常驻 |
| Ⅴ | **磐誓** | 主动 | 免疫击退与位移 10s，破甲抗性 +50% | 40s |
| Ⅵ | **壁立** | 终极 | 每战一次：8s 内全队不死（生命最低锁 1），期间你不能移动或攻击 | 每战 1 次 |

- **可装备武器**：主用 **剑 + 盾、战戟、锤**；可用 **长枪、斧**；**禁用** 弓 / 弩 / 铳 / 投掷 / 法杖 / 魔法书 / 触媒 / 晶刃 / 爪 / 鞭（07 册 20 类口径）
- **防具**：重甲、盾（盾为壁卫线唯一可持盾者）；穿布袍时格挡 -30%，穿轻甲无加成
- **属性成长**：侍从阶 体魄 C / 意志 C → 誓约阶 体魄 A / 意志 B → 冠冕阶 体魄 A / 意志 A（每阶永久 +1 格挡等级）
- **词条亲和**：沉岳、摧山、反刺、负重、盘石（07 册 24 前缀）
- **晋升条件**：侍从→誓约「掩护三个平民撤出兽群且无人受伤」；誓约→冠冕「磐石日于卡尔索神殿守一座门一夜，不后退一步」
- **侧重方向联动**：**磐石**。升阶解锁「镇守等级」：Ⅱ 静止减伤、Ⅳ 静止全防、Ⅵ 静止领域化（队友共享不死）。**不可召宠物、不可骑乘**（00A 3.3.3）

### 2.2 锋决线：试刃侍从 → 双锋决斗者 → **绯刃剑圣**

**奉神**：奥瑞恩（铸形者·金）／锻造 ｜ **冠冕词根**：万炉之锤 · 双锋（一去一回的决断）
**起源**：城市街巷。镖师、角斗场、下城区的恩怨——一把刀太慢的地方，人们学会了第二把。**刀要磨、刃要淬，这行归奥瑞恩管**。

**社会位置**：灰色地带。上不了正席，但有钱人夜里都睡得着，因为巷刃在巡街。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **试刃侍从** | 双持：副手持刀伤害 60% |
| 二阶 | **双锋决斗者** | 连影：三连击，第三击必暴 |
| 三阶 | **绯刃剑圣** | 一闪：0.5 秒内位移到目标背后并全额暴击（每战两次） |

> 「第一刀问路。第二刀办事。」

**技能表**（6 技）

| 技 | 名 | 类型 | 效果 | 冷却 / 消耗 |
|---|---|---|---|---|
| Ⅰ | **双持** | 被动 | 副手刀伤害 60%，攻速 +10% | 常驻 |
| Ⅱ | **问路** | 主动 | 突进 3m 并造成 80% 伤害，命中后 3s 内下一击必中 | 8s |
| Ⅲ | **连影** | 主动 | 三连击，第三击必暴（×1.8） | 12s |
| Ⅳ | **回刃** | 被动 | 每次暴击使下一击攻速 +12%，最多叠 3 层 | 常驻 |
| Ⅴ | **绯锋** | 主动 | 10s 内暴击伤害 +40%，但自身承伤 +15% | 35s |
| Ⅵ | **一闪** | 终极 | 0.5s 内位移到目标背后并全额暴击 | 每战 2 次 |

- **可装备武器**：主用 **刀、匕首、短剑（可双持）**；可用 **剑**；**禁用** 巨剑 / 巨斧 / 锤 / 链锤 / 战戟 / 弓 / 弩 / 铳 / 法杖 / 魔法书 / 触媒 / 晶刃 / 爪 / 鞭
- **防具**：轻甲；重甲使攻速 -25%、暴击率 -10%（双锋靠身法，不靠甲）
- **属性成长**：侍从阶 灵巧 B → 誓约阶 灵巧 A / 感知 B → 冠冕阶 灵巧 A / 感知 A（每阶永久 +5% 攻速）
- **词条亲和**：裂甲、贯甲、千刃、逐风
- **晋升条件**：侍从→誓约「在角斗场连胜三场且不使用药」；誓约→冠冕「千锻日于杜尔姆神殿呈一把自己磨的刀，由印契铁匠验刃」
- **侧重方向联动**：**铁躯**。升阶解锁「淬体等级」：Ⅱ 肌腱强化（位移距离 +1m）、Ⅳ 骨密度（暴击后减伤 10%）、Ⅵ 一闪可连出两次。**不可召宠物**

### 2.3 弓戍线：拾羽学徒 → 逐风游侠 → **穿云猎师**

**奉神**：埃俄隆（赋息者·风）／疾行 ｜ **冠冕词根**：归风长弓（射透云层）
**起源**：瑟兰迪尔氏族的猎手传统 + 王国边军哨所。猎手编入军制后，"看住林子"成了兵役。**箭射出去还会回来的说法，从埃俄隆的归风长弓来**。

**社会位置**：希尔凡林地里是本事，王国军里是"辅兵"。城里人管他们叫"守林的"。

| 阶 | 名字 | 能力 |
|---|---|---|

- **属性成长**：侍从阶 魅力 B / 心智 C → 誓约阶 魅力 A / 心智 B → 冠冕阶 魅力 A / 心智 A（每阶永久 +5% 议价）
- **词条亲和**：水浸、踏浪、亲和、拾荒
- **晋升条件**：侍从→誓约「不靠差价，靠一条新路赚到第一桶金」；誓约→冠冕「潮汐日于马雷纳把第一网里那条鱼扔回海，再做成一笔不赚钱的生意」
- **侧重方向联动**：**形变**。升阶解锁「流通等级」：Ⅱ 押货、Ⅳ 跨域汇兑、Ⅵ 开商路。**不可召宠物**；12 册货币 / 任务物品与 06 册柱日停业规则在此线交汇

## 六、专属职业（7 个）

**专属职业不是转职来的，是身份——只有特定的人能持有。七席各登记在一柱神下，但同样不是神选。**

### 6.1 【主角专属】测程线：测绘学徒 → 量地官 → 定线人

**奉神**：托帕斯（空间·折界星盘）

**来历**：王家测绘局的职级序列。干线工程启动，局里把老、弱、闲散人手全派出去测绘——你就是被派出去的那个（主线入口）。**测杆是折界星盘的遗器形制**，局里没人这么说了，但制图室的门楣上还刻着托帕斯的神徽。

| 阶 | 名字 | 能力 |
|---|---|---|
| 一阶 | **测绘学徒** | 测杆：探索地图记录 +30%；发现隐藏路径 |
| 二阶 | **量地官** | 量地：任意两点间生成"拟建路线"（预览未来铁路走向——剧情工具+快速旅行规划） |
| 三阶 | **定线人** | 定线：**主线终局权限**——干线东段的最终走向，由你的测绘报告决定（三结局的技术入口） |

**为什么只有主角**：全局只有一人能走到"定线人"——因为走到三阶需要的东西（那段被造过假的原始数据）在主角手里。

> 「局长说：地图是刀。画线的人决定谁的田被切开。」

### 6.2 【NPC 专属】织印人 · 宰相府密探（一人）

**奉神**：倪克丝（暗·抹迹）

只属于王都宰相的暗线职位。伪造印信、文书、测绘数据的黑手——**主线数据造假的源头**就是他。玩家在三阶支线"纸上的河"里第一次见到他的作品（一份完美的假地形图）。**他做的是"让纸上的河看起来真"，是抹迹之道被人用歪了的样子**。

**能力**（敌方）：伪造一切官方文件；可替换 NPC 身份（剧情杀）。

### 6.3 【NPC 专属】守矿使 · 杜尔姆独一职位（一人）

**奉神**：奥瑞恩（金·万炉之锤）

杜尔姆对辉石脉的**首席判断官**——她说这条脉能采就采，说不能就没人敢下镐。现任守矿使**巩铁婆**（瓦尔迪恩人，八十岁，矿难遗孤的养母）。

**剧情位置**：静谷活矿脉的判定权在她手里——她是主线两边都想争取的人。她的判断方式是"贴脉听三天"，没人知道她在听什么。

### 6.4 【NPC 专属】静纹使 · 静纹院首座（一人）

**奉神**：克罗涅斯（时间·永漏之冠）

灰姑的职位。**纹满三年还没走完的人**——历史上没有一个静纹使者活到卸任。她管理静纹院，也是全大陆唯一能"读石纹"的人（摸你的手臂，说出你引过多少咒、哪一道是你最舍不得的）。

**剧情位置**：咒锋线、引咒线的三阶传承任务都经过她；伊格尼人诉讼案的关键证人。

### 6.5 【NPC 专属】护路督军 · 护路军统帅（一人）

**奉神**：忒拉蒙（土·定岳之柱）

铁澜的职位。佣兵出身、杜尔姆战争的老兵、商会最锋利的一把刀。他不是反派——**他是在"没有名分的军队"里想活到退役的聪明人**。

**剧情位置**：护路军任务线的终局选择给他"名分"还是"揭旧案"；草原拔轨事件的镇压命令由他签发。

### 6.6 【NPC 专属】司秤人 · 拾遗会会首（一人）

**奉神**：希莱昂（物质·未刻王坯）

秤婆的职位。拾遗会的规矩：会首必须能**"称出来历"**——一件遗物放上天平，她说出它从哪来（服务端设定上是鉴定系统的人格化身）。传位方式：秤倾斜两次，传给让她看走眼的人。**"东西得有分量"，是希莱昂留给这一行的话**。

**剧情位置**：遗器鉴定的入口 NPC；**遗辉守望者**传承试炼的最后一道题由她出。

### 6.7 【NPC 专属·伙伴】第七型 · 诺克的原型编号

**奉神**：刻拉诺斯（电·不绝之弦）

伊格尼人伙伴**诺克**的专属职业。它是炉历 90 年第一台傀的原型机（编号第七），第九批之前、又"怕疼"之后的**孤例**。它自己不知道自己是什么。

**能力**：独有的"存档"机制（每章可存一次"人格快照"——死亡时从快照恢复，但丢失快照之后的记忆，与伊格尼人诉讼案的"存档权"直接呼应）。

**剧情位置**：伊格尼人诉讼案的活证据；它的选择（公开编号 / 保持沉默）是伊格尼人线的终局。
