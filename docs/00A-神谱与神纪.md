# 00A · 神谱与神纪

> 《定线人》设定集 第〇册（甲）· 神谱卷
> **十四柱、三席、六根道、十四裔、一部神纪。**
> 这一册是所有其他册子的上游：种族、武器、装备、神器、宠物、职业、词条、地区、民俗、剧情，全部从这一册长出来。
>
> **一句话**：十四位神曾为「形先还是息先」争过一次，为「该不该下界」争过第二次，最后共同立约缄默。现在他们高居高天，不显圣、不回话、不授谕；人间只剩下他们的血、他们的器、他们的职、他们的地和他们的节。

## 一、这一册解决什么

### 1.1 引入神，但不推翻旧世界

原设定里三条硬骨头保住，一条改写：

| 原设定 | 处置 |
|---|---|
| 人是本地长的，没有外来的祖先 | **保住**。神没有造人。地上先有生灵，神把十四道「息」吹进去，生灵才分出十四种「性」。人仍是洛雷亚土生土长的 |
| 历史连续，从河谷争水一路走到铁路时代 | **保住**。神纪不是人的历史，是「高天的事」，与人间年表并行不叠加。人间史上没有断代、没有失落的古文明、没有一夜消失的帝国 |
| 不做世界拯救者，终局对手是公文与账目 | **保住**，且写死为本册第七节的缄默律 |
| 禁词：地狱、深渊、虚空、混沌、上古、失落、神选、天命 | **改写**。世界里有神，但没有「神选」「天命」「上古」「失落」这些概念——神不选人、不下谕、不设末世；「地狱/深渊/虚空/混沌」仍是外来词，禁用 |

### 1.2 神在哪里

**高天**：不是天上，是「上面」。人抬头看见的那道**光帘**，就是高天的垂帘——暗神在缄默之约后覆上去的一层"痕迹盖布"，把上头的事盖住了。两颗月亮在帘外，光帘在帘内，谁也没穿过去过。

凡人对高天的全部知识来自三样东西：**裔器上的刻纹、祭祀里的旧词、和祖先传下来的自称**。没有经文，没有神像（禁止造像，见第六节「覆痕」），没有活着见过神的人。

## 二、缄默律（当前时间线 · 炉历 212 的硬规则）

**这一节是红线，写给剧情、任务、UI、文案。违反即作废。**

1. **神不现身**。全程 25–30 小时主线、全部支线、全部结局，不出现神、神的化身、神的分身、神的梦境、神的声音。
2. **神不授谕**。凡间任何「我得到神谕」「神选中了我」的角色，一律是骗子、误读，或**神鸣**（第五节）造成的巧合。没有例外。
3. **神不干预结果**。祈雨不灵，诅咒不验，祭品不换保佑。柱日祭的作用是**让人聚起来、让店关门、让账停下来**，这是社会学效果，不是神迹。
4. **神只有五条合法通道**：**血脉**（种族能力）、**裔器**（装备）、**神职**（职业与教团）、**神壤**（地区与地貌）、**柱日**（历法与民俗）。除此之外，神对人间不起作用。
5. **超自然现象必须有自然解释**。辉石会生长、傀人怕疼、光帘发亮、兽潮南下，行会、商会、村里各有一套世俗说法；神纪提供第六种说法，**但没人能证实，剧情永不证实**。

> **设计上的一句话**：神是这套世界观的**语法**，不是角色。玩家一辈子不会见到他们，但玩家说的每一句行话、穿的每一件甲、过的每一个节，都是他们留下的语法。

### 2.1 三个「没人懂的留白」的新解（不解释，只并列）

01 册原有三处留白保持「不解释」，本册只补一句**神学侧的说法**，与世俗说法并列，供文案取舍：

| 留白 | 世俗说法 | 神纪说法（无人证实） |
|---|---|---|
| 辉石为什么会生长 | 行会：大地的血；商会：矿床结晶 | 能量神「初纹石」的余息，物质神给了它形，所以既长、又有重量 |
| 兽潮的巨兽从冰原哪里来 | 极寒饿极了南迁 | 照世之灾时被照坏的一支息，缄默后被暗神赶到帘外极北 |
| 傀人第九批为什么开始怕疼 | 商会：零件公差 | 电神传约时漏下的一缕「不绝线」，落在了第九批的回路里 |

## 三、能力方向：六根道 × 十四神道

用户原始设想的「肉体 / 精神 / 机械 / 召唤」四类太粗，且彼此不在同一层。整理成**两层**：

### 3.1 六根道（能力从哪里来）

| 根道 | 管什么 | 落到系统里 |
|---|---|---|
| **躯道** | 肉体开发、器官变异、生体共生、硬化、感官特化 | 种族身体能力、器官变异、宠物特殊器官、怪物掉落器官 |
| **识道** | 精神、咒文、感知、意志、幻象、恐惧、记忆 | 心智/感知/意志、石纹、咒术武器、幻象与隐匿词条 |
| **器道** | 机械、装甲、热武器、构装、回路、传导 | 铳/弩/驱甲/傀人、载具、改装件、机工与锻铸职业 |
| **契道** | 契约兽、召唤、使役、羁绊、命名、协同 | 宠物与伙伴、驭兽/傀操职业、盟誓类词条、好感度 |
| **质道**（新增） | 元素流变、赋形、铸炼、质量、承载、塑性 | 十四属性、晶核、材料、防具、赋形与流变类词条 |
| **序道**（新增） | 时间、空间、界线、预知、收纳、位移、静止 | 测绘与观星、地图、缓续/挪移类词条、静止领域、时节后缀 |

原始四类是前四根道的俗名：**肉体=躯、精神=识、机械=器、召唤=契**。新增两根道补上了「元素/物质」和「时空/秩序」两个大空档——否则十四属性里的金木水火土、时间空间物质能量全都无处安放。

### 3.2 十四神道（每位神一条，是六根道的组合）

| 神 | 主道 | 副道 | 神道名 | 一句话机制 |
|---|---|---|---|---|
| 金 | 器 | 质 | **锻构** | 打造、署名、破甲、耐久；器物有"印" |
| 木 | 躯 | 契 | **共生** | 嫁接、器官变异、活体装备、记忆型治疗 |
| 水 | 质 | 躯 | **流变** | 变形、塑形、适应、恢复、涉水 |
| 火 | 质 | 器 | **燃发** | 过载、爆发、消耗换输出、一次性 |
| 土 | 躯 | 序 | **凝守** | 硬化、静止领域、不退、耐久与记忆 |
| 风 | 躯 | 序 | **疾行** | 位移、坐骑、滑翔、追击、返回 |
| 光 | 识 | 质 | **照显** | 照明、显形、净化、幻象；照见即被照见 |
| 电 | 器 | 识 | **传导** | 连锁、信号、神经加速、指令、击发的一瞬 |
| 音 | 契 | 识 | **共鸣** | 契约、命名、召唤、指挥、群体协同 |

| 能量 | 识 | 质 | **引注** | 咒术、注能、石纹代价制、能量过身 |

**种族继承的是神道，不是神力**：神之裔不会放神技，他们的身体、器官、装备槽、能走与不能走的职业线，是神道在血里长了千百年的形状。例：土裔岩民不是"会土魔法"，是新陈代谢慢到能活四百岁、沉得像真石头、且永远躲不开攻击。

### 3.3 侧重方向（修向）：一族一向，各系统联合设计

> 用户原始设想：「肉体开发 / 器官异化 / 魔法 / 机械 / 契约兽」是角色侧的**玩法主轴**；每种可再细分——肉体开发可走重甲、可走硬化；器官异化可异化眼睛、四肢、大脑；魔法只拿法杖/魔法书；机械可穿装甲也可遥控；契约兽与宠物一起进化。
> 本册的处理：**把「侧重方向」立为种族层的主干——十四裔，每一裔恰好绑定一个侧重方向（一族一向）。** 方向不是"可选流派"，是这族血里长出来的玩法：神道在血里长成了身体，身体长成了玩法。它再向下贯穿武器、词条、装备、宠物、道具、晋升——**改一个方向，要同时看这一整行**（3.3.2）。

#### 3.3.3 两条跨系统硬规则（写给 04 / 07 / 09）

1. **魔道武器限定**：凡走「咒术」「显影」两条术道的职业/角色，**只能装备 法杖 / 魔法书 / 触媒 / 晶刃** 四类武器；其余十二个方向不可装备这四类（强行装备则法术槽不可用、对应词条不触发）。水、时间二柱本就不授兵器，故其上裔（岬、候）无近战武器类，只有塑甲/面具/时节后缀——07 册授形神表的既有设定，在此被纳入方向规则统一解释。
2. **召唤/骑乘限定**：全大陆**只有「契约」「骑驭」两个方向能召/骑**——契约唤**息兽**（09 册宠物，与主人同进化），骑驭骑**坐骑**（非息兽，是独立坐骑系统）。其余十二个方向**完全不能召唤宠物、不能骑乘**；09 册 30 件宠物装备只对这两个方向生效，息兽的「唱名立契」也只在这两方向开启。

> 这两条规则让"各系统联合设计"变成硬约束：一个种族的侧重方向，直接决定它能拿什么武器、穿什么甲、能不能带宠物、靠什么升级。**玩家选族即选玩法。**

## 五、阵营：形席 · 息席 · 衡席

### 5.1 三席在争什么

| 席 | 柱数 | 主张 | 成员 |
|---|---|---|---|
| **形席** | 6 | **形先于息**：先定形、定界、定时刻，东西才存在 | 坯母（基座）、砥王（首席）、磐公、界卿、候主、照世者（削席） |
| **息席** | 6 | **息先于形**：先有流动、生长、过身，形只是息一时的样子 | 青妪、汐君、炉母、长蹄、千喉、引息（末席） |
| **衡席** | 2 | 不站边。**一柱传话，一柱抹痕**，只守缄默之约 | 弧使、缄影 |

形席与息席不是善恶，是两种对"什么东西算存在"的判断。**这场争论在人间投下的影子，就是咒术（手引，息过身）与机工（炉烧，定形器）两派互相看不起了一百年。**

### 5.2 阵营关系

|  | 形席 | 息席 | 衡席 |
|---|---|---|---|
| **形席** | 内部按"座次"排，坯母不争 | 旧怨未消，已停战 | 敬而远之（怕被抹痕） |
| **息席** | 旧怨未消，已停战 | 松散，各管各族 | 怨其"传了约就撒手" |
| **衡席** | 不评价 | 不评价 | 二柱分工，从不合议 |

### 5.3 神际旧账 → 人间投影（**这张表是设定咬合的核心**）

人间所有仇恨与亲近，往上追都能追到高天的一笔旧账。当地人不知道，只知道"我们家从来跟他们家不对付"。

| 神与神 | 高天旧账 | 人间现在的样子 |
|---|---|---|
| 砥王 ↔ 引息 | 量衡之争的首席对末席：形先 vs 息先，吵得最凶 | **纹人 ↔ 诺尔人 -2**，行会与矿盟百年税争（02 册全表最低） |
| 砥王 ↔ 磐公 | 共铸北垒之基，磐公替砥王背了两百年的死者名单 | **岩民 ↔ 诺尔人 +2**，矿难名单世代背诵（全表最高） |
| 炉母 ↔ 坯母 | 初炉要烧原坯，坯母不肯给 | 铎港 ↔ 王都：工厂要料，王室要税，特许权之争 |
| 青妪 ↔ 砥王 | 铁器换木材，一个要砍一个要长 | 《林界约》与枕木特许权 |
| 汐君 ↔ 炉母 | 帆船与辉石船，一个随流一个烧火 | 白帆商盟的内部革命 |
| 界卿 ↔ 候主 | "线该画在哪里" vs "线该画在何时"，两柱至今不合 | 王家测绘局与观星台互不服气；干线听证里"程序"与"数据"之争 |
| 照世者 ↔ 缄影 | 削席那日，缄影替她覆了痕迹 | 曜人与默人互不通婚，也互不揭发 |
| 弧使 ↔ 千喉 | 唯一还在"说话"的两柱：一柱传字，一柱命名 | 神职里只剩「传令」与「唱名」两种仪式还自称能通高天（其实不能） |
| 青妪 ↔ 引息 | 一个把息养在身体里，一个让息穿过身体 | 咒术行会的两派、静纹院与纹城 |

## 六、神纪 · 大事件表

> **纪年说明**：神纪用「纪」不用「年」——高天没有人间的时间。神纪在旧历 0 年之前全部结束，**与 01 册连续年表不重合、不换算、不设对照**。凡人不知道神纪有过多长，教会也不知道。
> **读法**：每一行最后一列是"这件事在人间留下了什么"。**没有留下列的东西，不许出现在游戏里。**

| 纪 | 事件 | 谁在做 | 结果 / 人间留下的东西 |
|---|---|---|---|
| 一 | **立坯** | 坯母以自身为基座，形席六柱立起高天 | 洛恩大陆有了"底"：地质、重力、一切东西有重量 |
| 二 | **分息** | 息席六柱向地上生灵吹息，形席各认一族 | **十四神之裔**成形。人仍是本地长的，只是从此分了十四种性 |
| 三 | **量衡之争** | 形席（形先） vs 息席（息先），第一次神争 | 谁也没赢。人间留下的影子：**手引 vs 炉烧** |
| 四 | **铸器** | 十四柱各铸一件原初神器，作为"不下场也能作工"的凭依 | **十四原初神器**。这是"神器"这个概念的源头 |
| 五 | **照世之灾** | 照世者见人间极寒、兽潮，怜之，携照世镜下界显圣 | 被照到的地方形与息同时失序：**孽息怪物、畸晶、兽潮的远祖**。这是诸神唯一一次下界 |
| 六 | **缄默之约** | 弧使传约、缄影覆痕，十四柱共誓 | 神不再以真身、真名、真器临世；十四神器不许留在下界，碎作投影散落 → **30 件裔器 + 20 件神鸣余物** |
| 七 | **削席** | 照世者自请熄光，形席空出一柱（「缺柱」） | 曜人自此不点明灯、不造神像；形席六柱只剩五个座次，第六个空着 |
| 八 | **垂帘** | 缄影把高天的痕迹覆成一道天幕 | **光帘**（01 册天象）。从此抬头只能看见帘，看不见帘后 |
| 九 | **余息** | 神迹渐止，只剩四道「神鸣」 | 辉石生长、光帘、双月、兽潮。人间把它们当自然现象，各有一套世俗解释（见 2.1） |
| 十 | **人间史启** | 与神无关 | 旧历 0 年，河谷部落争水 → 01 册连续年表**从这里开始，一环扣一环** |
| 十一 | **炉历 212（现在）** | 无人 | 缄默已久。有人开始不信神，有人把柱日过成了放假。**主线只关于地与线** |

### 6.1 两条不能破的规矩

1. **神纪只有十一行。** 不许补"第十二纪觉醒/神归来/神谕重现"——那是救世主故事，本作不做。
2. **真名不可念。** 十四真名只刻在原初神器的内侧，神器不下界，所以人间无从得知。凡间典籍里出现的「真名」一律是伪作（织印人那类人最爱造这个）。下表列出真名是**给设定集读者的上帝视角**，不是给游戏内角色看的。

### 8.2 神壤 ≠ 国界（**这是政治冲突的来源**）

- 纹壤（能量）与静谷活矿脉叠在一起，却归王国勘测 → 干线走向之争
- 炉壤（火）在铎港城内，法律上却归商会财产 → 傀人诉讼案

## 九、神职命名法：职业名为什么长这样

> 用户举例过"地狱使徒"这种带教团感的复合名，但那是举例、不是模板，且本世界**没有"地狱"这个概念**（禁词）。因此三阶**不套统一后缀**，而是**一线一称、按活计特性取**：有的叫"师"（造物的、铸印的、读天的、调味的），有的叫"手"（射穿云的、贯铁的），有的叫"客"（折尺量路的、深入矿坑的），有的叫"夫 / 者 / 将 / 长"。词根仍只取自本世界的神名、尊号、神器、神壤——**不是搬一个外来词，是让这个名字只能在这个世界被取出来。**

### 9.1 三阶 = 神职三阶

| 阶 | 称谓 | 语法 | 出处 |
|---|---|---|---|
| 一阶 | **役名** | `［动词］童 / ［器物］徒 / ［场所］人` | 神庙、行会、工厂、村落里真实干活的杂役 |
| 二阶 | **职名** | `［职司］司 / ［誓约］执事 / ［守物］守` | 能靠这行吃饭了，在神职册上有了名字 |
| 三阶 | **正称** | 一线一称，贴合本行活计（师 / 手 / 客 / 夫 / 者 / 将 / 长 等） | 只取自该神的尊号、神器或神壤；**全大陆共 20 个，不许新增** |

**"正称"不是神选，是职称。** 教会里的原意是"被这一柱的活儿使唤了一辈子的人"。没有任何仪式、没有神谕、没有选中——转职任务仍然是"证明你懂这行"（04 册原规则不动）。

## 十二、自检（这一册有没有守住旧世界）

| 检查项 | 结果 |
|---|---|
| 有没有失落的古文明 / 断代史 | 没有。神纪与人间史并行，旧历 0 年起仍一环扣一环 |
| 有没有"神选 / 天命 / 救世主" | 没有。正称是职称，转职靠证明懂这行 |
| 主线里神会不会下场 | 不会。第二节缄默律是硬红线 |
| 终局对手是不是魔王 | 不是。仍是织印人，仍是公文与账目 |
| 会不会多出一套与玩法无关的空设定 | 不会。第十节每个系统都有对应落点，每条设定都改变玩家做什么/怎么想 |
| 一个种族是不是只对应一种玩法 | 是。3.3 节「一族一向」：14 裔各绑 1 个侧重方向，武器/词条/装备/宠物/晋升逐向绑定，选族即选玩法 |
| 命名有没有外来词 | 没有。地狱/深渊/虚空/混沌/上古/失落仍禁用；"正称"词根全部来自本世界神名与神器 |
