# 00A · 神谱与神纪

> 《定线人》设定集 第〇册（甲）· 神谱卷
> **十四柱、三方、六根道、十四裔、一部神纪。**
> 这一册是所有其他册子的上游：种族、武器、装备、神器、宠物、职业、词条、地区、民俗、剧情，全部从这一册长出来。
>
> **一句话**：十四位神曾为「形先还是息先」争过一次，为「该不该下界」争过第二次，最后共同立约缄默。现在他们高居高天，不显圣、不回话、不授谕；人间只剩下他们的血、他们的器、他们的职、他们的地和他们的节。

## 一、这一册解决什么

### 1.1 引入神，但不推翻旧世界

原设定里三条硬骨头保住，一条改写：

| 原设定 | 处置 |
|---|---|
| 人是本地长的，没有外来的祖先 | **保住**。神没有造人。地上先有生灵，神把十四道「息」吹进去，生灵才分出十四种「性」。人仍是洛雷亚土生土长的 |
| 历史连续，从河谷争水一路走到铁路时代 | **保住**。神纪不是人的历史，是「高天的事」，与人间年表并行不叠加。人间史上没有断代、没有失落的古文明、没有一夜消失的帝国 |
| 不做世界拯救者，终局对手是公文与账目 | **保住**，且写死为本册第七节的缄默律 |
| 禁词：地狱、深渊、虚空、混沌、上古、失落、神选、天命 | **改写**。世界里有神，但没有「神选」「天命」「上古」「失落」这些概念——神不选人、不下谕、不设末世；「地狱/深渊/虚空/混沌」仍是外来词，禁用 |

### 1.2 神在哪里

**高天**：不是天上，是「上面」。人抬头看见的那道**光帘**，就是高天的覆幕——暗神在缄默圣约后覆上去的一层"痕迹盖布"，把上头的事盖住了。两颗月亮在帘外，光帘在帘内，谁也没穿过去过。

凡人对高天的全部知识来自三样东西：**遗器上的刻纹、祭祀里的旧词、和祖先传下来的自称**。没有经文，没有神像（禁止造像，见第六节「缄默圣约」），没有活着见过神的人。

## 二、缄默律（当前时间线 · 炉历 212 的硬规则）

**这一节是红线，写给剧情、任务、UI、文案。违反即作废。**

1. **神不现身**。全程 25–30 小时主线、全部支线、全部结局，不出现神、神的化身、神的分身、神的梦境、神的声音。
2. **神不授谕**。凡间任何「我得到神谕」「神选中了我」的角色，一律是骗子、误读，或**神鸣**（第五节）造成的巧合。没有例外。
3. **神不干预结果**。祈雨不灵，诅咒不验，祭品不换保佑。柱日祭的作用是**让人聚起来、让店关门、让账停下来**，这是社会学效果，不是神迹。
4. **神只有五条合法通道**：**血脉**（种族能力）、**遗器**（装备）、**圣职**（职业与教团）、**神壤**（地区与地貌）、**柱日**（历法与民俗）。除此之外，神对人间不起作用。
5. **超自然现象必须有自然解释**。辉石会生长、伊格尼人怕疼、光帘发亮、兽潮南下，行会、商会、村里各有一套世俗说法；神纪提供第六种说法，**但没人能证实，剧情永不证实**。

> **设计上的一句话**：神是这套世界观的**语法**，不是角色。玩家一辈子不会见到他们，但玩家说的每一句行话、穿的每一件甲、过的每一个节，都是他们留下的语法。

### 2.1 三个「没人懂的留白」的新解（不解释，只并列）

01 册原有三处留白保持「不解释」，本册只补一句**神学侧的说法**，与世俗说法并列，供文案取舍：

| 留白 | 世俗说法 | 神纪说法（无人证实） |
|---|---|---|
| 辉石为什么会生长 | 行会：大地的血；商会：矿床结晶 | 能量神「初纹辉晶」的残息，物质神给了它形，所以既长、又有重量 |
| 兽潮的巨兽从冰原哪里来 | 极寒饿极了南迁 | 垂照之陨时被照坏的一支息，缄默后被暗神赶到帘外极北 |
| 伊格尼人第九批为什么开始怕疼 | 商会：零件公差 | 电神传约时漏下的一缕「不绝之弦」，落在了第九批的回路里 |

## 三、能力方向：六根道 × 十四神道

用户原始设想的「肉体 / 精神 / 机械 / 召唤」四类太粗，且彼此不在同一层。整理成**两层**：

### 3.1 六根道（能力从哪里来）

| 根道 | 管什么 | 落到系统里 |
|---|---|---|
| **躯道** | 肉体开发、器官变异、生体共生、硬化、感官特化 | 种族身体能力、器官变异、宠物特殊器官、怪物掉落器官 |
| **识道** | 精神、咒文、感知、意志、幻象、恐惧、记忆 | 心智/感知/意志、石纹、咒术武器、幻象与隐匿词条 |
| **器道** | 机械、装甲、热武器、构装、回路、传导 | 铳/弩/驱甲/伊格尼人、载具、改装件、机工与锻铸职业 |
| **契道** | 契约兽、召唤、使役、羁绊、命名、协同 | 宠物与伙伴、驭兽/傀操职业、盟誓类词条、好感度 |
| **质道**（新增） | 元素流变、赋形、铸炼、质量、承载、塑性 | 十四属性、晶核、材料、防具、赋形与流变类词条 |
| **序道**（新增） | 时间、空间、界线、预知、收纳、位移、静止 | 测绘与观星、地图、延缓/位移类词条、静止领域、时节后缀 |

原始四类是前四根道的俗名：**肉体=躯、精神=识、机械=器、召唤=契**。新增两根道补上了「元素/物质」和「时空/秩序」两个大空档——否则十四属性里的金木水火土、时间空间物质能量全都无处安放。

### 3.2 十四神道（每位神一条，是六根道的组合）

| 神 | 主道 | 副道 | 神道名 | 一句话机制 |
|---|---|---|---|---|
| 金 | 器 | 质 | **锻造** | 打造、署名、破甲、耐久；器物有"印" |
| 木 | 躯 | 契 | **共生** | 嫁接、器官变异、活体装备、记忆型治疗 |
| 水 | 质 | 躯 | **流变** | 变形、塑形、适应、恢复、涉水 |
| 火 | 质 | 器 | **燃焰** | 过载、爆发、消耗换输出、一次性 |
| 土 | 躯 | 序 | **镇守** | 硬化、静止领域、不退、耐久与记忆 |
| 风 | 躯 | 序 | **疾行** | 位移、坐骑、滑翔、追击、返回 |
| 光 | 识 | 质 | **映照** | 照明、显形、净化、幻象；照见即被照见 |
| 电 | 器 | 识 | **传导** | 连锁、信号、神经加速、指令、击发的一瞬 |

**种族继承的是神道，不是神力**：神之裔不会放神技，他们的身体、器官、装备槽、能走与不能走的职业线，是神道在血里长了千百年的形状。例：土裔忒拉人不是"会土魔法"，是新陈代谢慢到能活四百岁、沉得像真石头、且永远躲不开攻击。

### 3.3 侧重方向（修向）：一族一向，各系统联合设计

> 用户原始设想：「肉体开发 / 器官异化 / 魔法 / 机械 / 契约兽」是角色侧的**玩法主轴**；每种可再细分——肉体开发可走重甲、可走硬化；器官异化可异化眼睛、四肢、大脑；魔法只拿法杖/魔法书；机械可穿装甲也可遥控；契约兽与宠物一起进化。
> 本册的处理：**把「侧重方向」立为种族层的主干——十四裔，每一裔恰好绑定一个侧重方向（一族一向）。** 方向不是"可选流派"，是这族血里长出来的玩法：神道在血里长成了身体，身体长成了玩法。它再向下贯穿武器、词条、装备、宠物、道具、晋升——**改一个方向，要同时看这一整行**（3.3.2）。

#### 3.3.3 两条跨系统硬规则（写给 04 / 07 / 09）

1. **魔道武器限定**：凡走「咒术」「显影」两条术道的职业/角色，**只能装备 法杖 / 魔法书 / 触媒 / 晶刃** 四类武器；其余十二个方向不可装备这四类（强行装备则法术槽不可用、对应词条不触发）。水、时间二柱本就不授兵器，故其上裔（涅瑞德人、艾欧恩人）无近战武器类，只有塑甲/面具/时节后缀——07 册定形神表的既有设定，在此被纳入方向规则统一解释。
2. **召唤/骑乘限定**：全大陆**只有「契约」「骑驭」两个方向能召/骑**——契约唤**契兽**（09 册宠物，与主人同进化），骑驭骑**坐骑**（非契兽，是独立坐骑系统）。其余十二个方向**完全不能召唤宠物、不能骑乘**；09 册 30 件宠物装备只对这两个方向生效，契兽的「唱名立契」也只在这两方向开启。

> 这两条规则让"各系统联合设计"变成硬约束：一个种族的侧重方向，直接决定它能拿什么武器、穿什么甲、能不能带宠物、靠什么升级。**玩家选族即选玩法。**

## 五、阵营：铸形者 · 赋息者 · 守衡者

**全称与简称**：**铸形者议会**（The Formwrights，简称**铸形者**）、**赋息者同盟**（The Quickening，简称**赋息者**）、**守衡者议会**（The Measurers，简称**守衡者**）。典籍、誓词与纹章用全称，正文一律用简称——三字、有元音、能一口气读顺（取名法见 9.1 第 5 条）。三方合称**万神殿**。

### 5.1 三方在争什么

| 阵营 | 柱数 | 主张 | 成员 |
|---|---|---|---|
| **铸形者** | 6 | **形先于息**：先定形、定界、定时刻，东西才存在 | 希莱昂（基座）、奥瑞恩（首席）、忒拉蒙、托帕斯、克罗涅斯、琉明娜（逊位） |
| **赋息者** | 6 | **息先于形**：先有流动、生长、过身，形只是息一时的样子 | 薇兰蒂、涅瑞娅、伊格妮丝、埃俄隆、卡莉俄涅、俄涅斯（末席） |
| **守衡者** | 2 | 不站边。**一柱传话，一柱抹痕**，只守缄默圣约 | 刻拉诺斯、倪克丝 |

铸形者与赋息者不是善恶，是两种对"什么东西算存在"的判断。**这场争论在人间投下的影子，就是咒术（手引，息过身）与机工（炉烧，定形器）两派互相看不起了一百年。**

### 5.2 阵营关系

|  | 铸形者 | 赋息者 | 守衡者 |
|---|---|---|---|

人间所有仇恨与亲近，往上追都能追到高天的一笔旧账。当地人不知道，只知道"我们家从来跟他们家不对付"。

## 六、神纪 · 大事件表

> **纪年说明**：神纪用「纪」不用「年」——高天没有人间的时间。神纪在旧历 0 年之前全部结束，**与 01 册连续年表不重合、不换算、不设对照**。凡人不知道神纪有过多长，教会也不知道。
> **读法**：每一行最后一列是"这件事在人间留下了什么"。**没有留下列的东西，不许出现在游戏里。**

| 纪 | 事件 | 谁在做 | 结果 / 人间留下的东西 |
|---|---|---|---|
| 一 | **肇基** | 希莱昂以自身为基座，铸形者六柱立起高天 | 瓦伦提亚大陆有了"底"：地质、重力、一切东西有重量 |
| 二 | **授息** | 赋息者六柱向地上生灵吹息，铸形者各认一族 | **十四神之裔**成形。人仍是本地长的，只是从此分了十四种性 |
| 三 | **形息之争** | 铸形者（形先） vs 赋息者（息先），第一次神争 | 谁也没赢。人间留下的影子：**手引 vs 炉烧** |
| 四 | **神器之铸** | 十四柱各铸一件原初神器，作为"不下场也能作工"的凭依 | **十四原初神器**。这是"神器"这个概念的源头 |
| 五 | **垂照之陨** | 琉明娜见人间极寒、兽潮，怜之，携照世明镜下界显圣 | 被照到的地方形与息同时失序：**畸息怪物、畸晶、兽潮的远祖**。这是诸神唯一一次下界 |
| 六 | **缄默圣约** | 刻拉诺斯传约、倪克丝抹迹，十四柱共誓 | 神不再以真身、真名、真器临世；十四神器不许留在下界，碎作投影散落 → **30 件遗器 + 20 件圣屑** |
| 七 | **逊位** | 琉明娜自请熄光，铸形者空出一柱（「缺柱」） | 琉明人自此不点明灯、不造神像；铸形者六柱只剩五个座次，第六个空着 |
| 八 | **覆幕** | 倪克丝把高天的痕迹覆成一道天幕 | **光帘**（01 册天象）。从此抬头只能看见帘，看不见帘后 |
| 九 | **残息** | 神迹渐止，只剩四道「神鸣」 | 辉石生长、光帘、双月、兽潮。人间把它们当自然现象，各有一套世俗解释（见 2.1） |
| 十 | **凡世之始** | 与神无关 | 旧历 0 年，河谷部落争水 → 01 册连续年表**从这里开始，一环扣一环** |
| 十一 | **炉历 212（现在）** | 无人 | 缄默已久。有人开始不信神，有人把柱日过成了放假。**主线只关于地与线** |

### 6.1 两条不能破的规矩

1. **神纪只有十一行。** 不许补"第十二纪觉醒/神归来/神谕重现"——那是救世主故事，本作不做。
2. **真名不可念。** 十四真名只刻在原初神器的内侧，神器不下界，所以人间无从得知。凡间典籍里出现的「真名」一律是伪作（织印人那类人最爱造这个）。下表列出真名是**给设定集读者的上帝视角**，不是给游戏内角色看的。

## 九、命名法典（全名对照 · 唯一真源）

### 9.1 取法：西方古典魔幻，不照搬

整套专名取法于**万神殿式神系 + 古典魔幻位阶**的传统：神有音译专名、有"××之主 / ××者"式尊号、有不可念的远古真名、有圣物式神器；族有音译族名与誓约别称；职业走 `扈从 → 骑士 → 冠冕` 三段位阶。参考的是**命名法**——多层专名、拉丁/希腊词根、带撇号的远古语、器物自带圣名——不是搬任何现成作品的专名。所有名字都是本世界自造，**没有一个专名与其他作品重复**。

六条硬规则：

1. **神名三层**：`音译名（拉丁转写）` → `尊号` → `真名（高天语，带撇号，人间从未被念出）`。神殿里只称音译名，典籍里写尊号，真名只刻在神器上。音译名**不超过三个汉字**，拉丁转写同音节数。
2. **神器自带圣名**：格式为 `器物名 · 专名（拉丁文圣名）`，参照"××之××（Hammer of … / Crown of …）"的圣物命名。三十件遗器只是它的影子，不配称圣名。
3. **族名不写"×人/×民"**：一律 `音译专名 + 人`（`-ar / -ei / -yr / -ion` 尾），另配一条**誓约别称**用于誓词与纹章。
4. **职业名是位阶，不是工种**：一阶 `扈从 / 学徒 / 侍从`，二阶 `骑士 / 术士 / 游侠 / 机师`，三阶 `守望者 / 大法师 / 领主 / 宗师`。**禁止"马厩徒、擦铳徒、灶下徒"这类以杂役活计命名的写法**——名字要写这行的理想，不写这行的杂活。
5. **不造拗口的生硬合成词**：禁止把**单字抽象概念硬接到建筑后缀**（"×殿 / ×庭 / ×廷"）或硬凑两个不搭的字。专名要三字左右、有元音、能一口气读顺；阵营名用 `××者 + 议会/同盟` 这类可直接念出来的词，全称给典籍用，简称给正文用。**判定标准：写进台词里念一遍，绕口就重取。**
6. **术语优先具象，禁用抽象字叠抽象字**：系统术语、神道、修向、柱日一律用能想出画面的词（遗器 / 圣屑 / 契兽 / 燃焰 / 铁躯 / 霜信日），**不造"裔器 / 孽息 / 授形 / 匿踪 / 未刻日"这类"抽象字 + 抽象字"或"否定词 + 抽象字"**。神纪事件名是例外，走典籍体（肇基 / 授息 / 神器之铸 / 逊位 / 覆幕 / 残息 / 凡世之始）。**生僻字（晷、幂、瓠…）与叠字（霜台晷台）一律不用。**
7. **成体系 ≠ 整齐划一**：同一组专名**后缀不许重复**（七个势力曾用"北境矿盟 / 牧盟 / 白帆商盟"，三个「盟」连排，已废）；**字数要参差交错**，不许一整排同长度（30 件遗器前 17 件全是两字、怪物 43 只两字，均已重排）。势力名用**音译专名 + 差异政体后缀**，不用"方位 + 物产 + 政体"的描述词拼装。给一组名字前，先把它们排成一列念一遍——**看着像表格填充，就重取。**
