# 01 · 星球与世界

> 《定线人》设定集 第一册
> 外星球档案、大陆地理、辉石能源、咒术与机工、连续历史年表、历法、交通。
> **一句话世界观：一颗外星球，海上浮着一块大陆。地下长着会发光的石头。有人把石头握在手里念咒，有人把石头扔进炉子烧机器。**

## 一、星球：洛雷亚

这是一颗外星球。它的天空、月亮、草木都和"地球"不一样，但住在这里的人不知道什么叫地球——对他们来说，这就是**世界本来的样子**。

| 项目 | 设定 |
|---|---|
| 星球名 | **洛雷亚（Lorea）** |
| 恒星 | 一颗偏橙的太阳。正午是金白色，傍晚红得像炉膛 |
| 卫星 | 两颗月亮：**银盘**（大，看暗斑认月份）、**灰豆**（小，一个月绕天两圈） |
| 特殊天象 | **光帘**：夜空一道竖着的微光纱幕，从东地平线挂到西。是行星上空的一圈尘埃，被太阳照得发亮 |
| 海洋 | 八成表面是海。大陆只有一块，加上群岛 |
| 大陆名 | **洛恩（Lorn）**，东西约 3000 公里，南北约 2400 公里 |
| 一天 | **26 小时**。太阳落得晚，下午特别长。农夫把 16 点之后叫"**第二下午**"，一天吃四顿饭 |
| 一年 | **384 天**，12 个月，每月 32 天 |
| 草木 | 草是**青灰色**的，春天泛蓝；树皮深紫，秋叶转金红。没有绿色的草——这里的叶子里长的是别的色素 |

**人是本地长的。** 洛文人、诺尔人、艾沃人……九个智慧种族都是这颗星球土生土长的。没有"外来的祖先"，没有失落的殖民地。他们的历史从河谷部落一路连续走到今天的铁路时代，没有断代。

## 二、能源：辉石

**这是整个世界的心脏，先把它讲明白。**

地底下长着一种半透明的石头，叫**辉石**。淡青色，握在手里微温，暗处发光。它像矿一样成脉，像庄稼一样**缓慢生长**——采空一条脉，几十年后会再长回来。

辉石里存着能量。这个文明的一切——火、光、力气、机器——全部从这块石头里来。

**取出能量有两种办法。这两种办法，就是"剑与魔法"和"科技"的分界线，也是这个世界全部冲突的来源：**

| | **手引（咒术）** | **炉烧（机工）** |
|---|---|---|
| 做法 | 把辉石握在手里，念咒文，能量穿过施术者的身体出来 | 把辉石装进铁炉里烧，能量推动齿轮和活塞 |
| 效果 | 火、风、光、力，随咒文变化 | 起重机、纺车、船、火车、路灯，昼夜不停 |
| 代价 | 能量过身体，皮下长**石纹**，纹满人亡 | 人没事，但机器和辉石都**贵** |
| 谁在用 | 咒术行会、军中咒师、乡村术士 | 机工商会、工厂、铁路、城市 |

酒馆里老人是这么总结的：

> **「同一块石头，用嘴引的是法师，用炉烧的是工匠。」**

### 石纹：魔法的代价

手引辉石时，能量会从身体里过一遍，留下发光的细纹，像树根一样从手背往胳膊上爬。纹路越多，能引的能量越大，人越虚弱。

| 阶段 | 表现 | 影响 |
|---|---|---|
| **无纹** | 普通人 | 只能引一阶咒文 |
| **手纹** | 手背到腕，几条细纹 | 二阶咒文。握手时别人看得见 |
| **满臂** | 整条手臂发光 | 三阶咒文。夏天也得穿长袖 |
| **过身** | 纹路爬过肩膀到胸口 | 四阶咒文。开始失眠、咳血 |
| **纹满** | 全身发光，人不能动 | 没有五阶。纹满的人会慢慢变成一块**石头** |

**石纹不可逆。** 纹满者由教会收进**静纹院**，安度最后几年。乡下人吓小孩的话是："再闹，让你去和满胳膊发光的人睡一屋。"

**这是这个世界对力量的回答：你可以变强，但石头会顺着你的胳膊往上爬。**

### 咒师与机师的地位

- 咒师：又敬又怕。军队要（一个咒师顶十个铳兵），平民躲（满臂发光的人住店要加钱）
- 机师：新兴的体面人。工厂主、铁路工程师、船厂技师，城市的中坚
- **两派互相看不起，而且各有道理：**
  - 咒术行会说：把会生长的辉石烧掉，是在吃种子
  - 机工商会说：让活人当管道过能量，是在烧人

## 三、大陆地理

### 3.1 六个区域

| 区域 | 地形 | 主要物产 | 主要居民 |
|---|---|---|---|
| **中央河谷平原** | 平原、大河、丘陵 | 粮食、棉花、布 | 洛文人 |
| **北方高地** | 高原、深谷、矿脉 | **辉石**、铁、石料 | 诺尔人 |
| **东部大森林** | 原始森林、河谷 | 木材、药材、毛皮 | 艾沃人 |
| **西部草原** | 草原、盐湖 | 马、羊、皮革 | 哈兰人 |
| **南部海岸** | 港湾、群岛、丘陵 | 鱼、盐、船 | 岬人、港城商人 |
| **东南旧矿区** | 采空的山丘、塌陷谷 | 旧矿坑（探险地）、废铁 | 少数居民、拾遗会 |

### 3.2 三条大河

都发源北方高地，向南入海。

- **长河**：最长，贯穿中央平原，王国的命脉
- **石河**：水急多石滩，不通大船，但沿岸水力足，磨坊和**早期工厂**都在这里
- **青河**：水缓，两岸森林，木材靠它运出来

**所有的老城市都在河边，所有的新城市都靠铁路。**

### 3.3 三个特殊地点

- **北垒**：北方防线，修了 128 年的石墙，防冰原巨兽南下（"兽潮"）。现在一半守军被抽去内战边上的矿区
- **旧矿坑**：东南百年采空区，塌陷后形成地下迷宫，每年塌方都会改道。**这是地牢和随机探索的来源**——不是古文明旧矿坑，就是普通的、连续历史里的矿
- **废战场**：炉历 121 年王国与矿盟战争的工事带，50 年了没人清理，武器还在泥里

### 3.4 天空与农时

农夫不看月历，看三个日子：「**开河**」（长河解冻，下种）、「**头霜**」（第一场霜，收最后一批豆）、「**封河**」（河面冻死，闭户）。这三个日子决定全年。

## 四、历史（连续年表）

**这一节是重点。历史必须一环扣一环，每个事件都是上一个事件欠下的账。没有断代，没有失落的纪元。**

纪年说明：**旧历**从王国建立算起；**炉历**从第一台辉石炉点火算起（两历并行使用，城市人用炉历，乡下人用旧历，换算就是炉历 0 = 旧历 762）。

### 4.1 年表

| 年份 | 事件 | 为什么会发生 |
|---|---|---|
| 旧历 0 | 河谷部落为争水打了三代，最后**洛恩王国**统一中央平原 | 争水打成一家 |
| 旧历 68 | 北方高地的诺尔人学会深井采矿 | 人口多了，浅矿不够 |
| 旧历 133 | 王国设**壁卫营**（常备重步兵） | 平原无险可守，只能靠人墙 |
| 旧历 201 | 王国与森林氏族签《林界约》 | 王国要木材，艾沃人要铁器 |
| 旧历 260 | 草原哈兰部族结成**牧盟** | 干旱扛不住，只能联合 |
| 旧历 312 | 南海港城结成**白帆商盟** | 海兽猖獗，单城打不过 |
| 旧历 388 | 连续歉收，王室立**望纱教**为国教 | 需要一套说法稳住人心 |
| 旧历 455 | 高地联盟宣布独立，《山口条约》 | 王国要矿，诺尔人不想交税 |
| 旧历 520 | **第一次兽潮**：冰原巨兽南下，联军死伤十余万 | 连年极寒，兽群南迁找食 |
| 旧历 561 | 开始修**北垒** | 兽潮会再来，只能修墙 |
| 旧历 689 | 北垒完工，用时 128 年，国库见底 | 墙比战争还贵 |
| 旧历 702 | 牧羊人捡到第一块**辉石**：握着取暖念祷词，草着了 | 山坡上的石头本来就是发光的 |
| 旧历 740 | **咒术行会**在纹城成立，咒文系统化 | 手引的人多了，必须有规矩，否则纹满者没人管 |
| **炉历 0** | 铎港铁匠**铎三娘**把辉石扔进锅炉，推动了活塞——**第一台辉石炉** | 她只是想省劈柴 |
| 炉历 18 | 铎港第一座纺织厂 | 炉子不挑人、不睡觉 |
| 炉历 31 | 辉石起重机进矿山；矿工兄弟会成立 | 机器吊得比人多，工钱却没涨 |
| 炉历 60 | 第一艘辉石船「青鳊号」下水 | 商盟缺不靠风的船 |
| 炉历 90 | 第一台**傀人**出厂（机关劳工） | 工厂缺人手，商会造了铁的 |
| 炉历 103 | 王都三条街装辉石路灯；军中列装**辉石铳** | 练一个铳兵二十天，养一个咒师十年 |
| 炉历 121 | **矿盟战争**：王国与高地矿盟开战，三年不分胜负，和谈 | 矿价加税积怨 + 王国缺钱。东南战场成了今天的废战场 |
| 炉历 140 | 第一条货运铁路：铎港—王都 | 战后重建要运铁 |
| 炉历 165 | 铁路联通三大城市；**护路军**成立 | 路通了，路上的税和治安要有人管 |
| 炉历 190 | **大陆干线**计划提出：一条贯穿六区的铁路 | 三大城市吃尽了铁路的好处，剩下的人也想要 |
| **炉历 212** | **现在**。干线东段开始测绘 | 路线怎么走，各方都在争 |

### 4.2 因果链

```
争水 → 统一 → 人口 → 要矿 → 高地开发 → 高地独立 → 王国缺钱
                                    ↓
歉收 → 立国教 → 教会做大（静纹院收容纹满者）→ 与王权有磨擦
                                    ↓
极寒 → 兽潮 → 修北垒 → 国库空 → 加税 → 矿盟战争 → 战后靠机工回血
                                    ↓
捡到辉石 → 行会垄断手引 → 铎三娘烧炉 → 机工革命 → 城市崛起
                                    ↓
铁路 → 财富重新分配 → 干线之争 → 【主角要测绘的那条线】
```

**每一段都是上一段的账。** 没有凭空出现的古代文明，没有一夜间消失的帝国。

### 4.3 三个"没人懂"的留白（故意的）

1. **兽潮的巨兽从冰原哪里来** —— 没人活着走到冰原深处
2. **辉石为什么会生长** —— 行会说是"大地的血"，商会说是"矿床的结晶"，都没有证据
3. **傀人第九批之后为什么开始"怕疼"** —— 商会说是零件公差，傀人自己不说话

这三件事不解释。**这是这个世界的人自己也没搞懂的事，不是设定漏洞。**

### 四个节日

- **点炉节**（炉历新年）：铎港全城熄灯一分钟，再一起点亮——纪念铎三娘的第一炉
- **开河日**：北方解冻，跑船的、种地的都祭长河
- **升帘夜**（秋分）：望纱教的大节，家家往光帘方向放灯，送走这一年去世的人
- **停锤日**（炉历 121 战争纪念日）：全大陆工厂停工一天，机师和咒师这一天不吵架

| 方式 | 速度 | 说明 |
|---|---|---|
| 步行 | 6 km/h | 第二下午很长，一天能走很远 |
| 马车 | 18 km/h | 官道，货运主力 |

## 七、日常生活（给美术和文案）

### 城市与乡下（科技不均匀，这是真实的历史状态）

- **铎港**：路灯、工厂烟囱、报纸、电车（市中心）、夜班工人。**没有煤气，没有电，一切机器都烧辉石**——机器的核心是一个拳头大的铁炉，炉膛里的辉石发着淡青光
- **王都**：老城墙里嵌着新路灯，三条街是亮的，其余靠油灯。贵族看不起工厂主，工厂主买得起贵族孙女
- **乡村**：牛耕、水磨、油灯。术士路过会被人围观，火车路过会被人围着看半天

### 吃什么

- 平民：黑面包、豆子、咸鱼、蓝草汤（青灰色的，地球人看着难受，本地人的日常）
- 小康：白面包、鸡肉、麦酒
- 富人：烤肉、葡萄酒、南方群岛的果（火车运来，贵三倍）

### 用什么钱

**银币**「角子」，一枚 = 一天饭钱。大额「辉票」（机工商会发行的纸币，乡下人嫌它是"纸"）。

### 怎么说话

- 工人：短句，机件名词多（"这事儿卡壳了"）
- 农民：方言重，喜欢用河和节气打比方（"急什么，还没开河呢"）
- 咒师：说话慢，念惯咒文的人嗓子省着用
- 商会的人：客气，绕，爱把"亏本"挂嘴边

## 九、给美术的关键词

- **外星感的三个抓手**：青灰色的草地（春天泛蓝）、两个月亮同天（银盘将落、灰豆正升的黄昏最好看）、夜空的光帘
- **正常的世界**：蓝的天、金红的秋叶、灰石红瓦。不搞奇观，不搞废土
- **科技质感**：不是蒸汽朋克的煤烟，是**辉石炉的淡青色辉光**——机器的炉膛透出青光，路灯是青白色的，工厂夜景像一片低垂的星
- **咒术质感**：施术者的手臂上有发光树根状的纹路，光照在脸上从下往上
- **贫穷和富裕同框**：牛车和火车并行在同一个画面里，这是这个时代最好的构图
