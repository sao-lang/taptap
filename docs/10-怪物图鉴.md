# 10 · 怪物图鉴

> 《定线人》设定集 第十册
> 100 种**畸息**（垂照之陨时失序的息），10 个生物类群。
> 类群是生态位，不是阵营。

---

## 一、怪物与种族的区别

| | 智慧种族 | 怪物 |
|---|---|---|
| 性质 | 有社会、语言、文化 | 野生动物或家养动物 |
| 行为 | 可谈判 | 只有本能 |
| 能力来源 | 咒术、天赋、技艺 | **特殊器官** |
| 死亡 | 会被记住 | 会被分解成材料 |

每只怪物都有一个**特殊器官**——一个不讲道理的器官，赋予它一项超自然能力。这个器官可以打下来做材料。所以"杀死它"和"用它"是同一件事。

## 二、威胁等级

| 等级 | 含义 |
|---|---|
| ★ | 无害或极弱 |
| ★★ | 有威胁，单挑可胜 |
| ★★★ | 需要策略 |
| ★★★★ | 需要准备，或绕路 |
| ★★★★★ | Boss 级 |

## 畸息：十类群的来路

**怪物不是神的造物，也不是神派来的。** 神纪第五纪「**垂照之陨**」，琉明娜携照世明镜下界，被照到的地方形与息同时失序——失控的那一部分息就是**畸息**，也就是这一册的十类群（00A 第六节）。当前时间线诸神缄默，剧情只围绕种族与地区，没有一只是"奉命下界"的。

**特殊器官**就是息在身体里凝成的形状，打下来能做材料——这正是第一节那句"**杀死它**和**用它**是同一件事"：打的是息，用的也是息，玩家不必问它从哪来，只要认得出打哪里。

| 类群 | 承神 | 为什么是这一柱 | 该类群掉落偏向 |
|---|---|---|---|
| **滩虫类** | 物质 · 希莱昂 | 小而多、食腐清道、全境都有、最没有特点——希莱昂给的礼物就叫"**正常**"，**赋形**是"什么都能长出来"的坯（00A 7.13）。玩家想：满地都是的底层材料就是通用坯料，别挑 | 通用基础材料：盐壳、撬颚、气囊、缝合腺等，多标"××材料"，走修理、开锁、浮力、绳索 |
| **甲壳类** | 金 · 奥瑞恩 | 防御高、速度慢、怕钝器，壳能直接当盾、当甲、当武器材料——**锻造**"凡有印、有刃、有甲处皆在其范围"，**不折**就是耐久与破甲（00A 7.1）。玩家想：打甲壳等于拆甲，拆下来自己穿 | 甲壳与防具/武器材料：背甲、铁壳、背刺、足盾、沉甲、螺壳 |
| **礁鱼类** | 水 · 涅瑞娅 | 只在渗水期出现，成群绕圈突然冲刺，随水来随水退——**流变**是"顺着势改自己的形"，口头禅"到时候"（00A 7.3）。玩家想：涨潮才来、跟着水走，别在退潮的礁盘上等它 | 随水期产出的鱼体与胶质材料：长喙（箭）、鲸须、鲨齿鲨皮、鳗皮、卵囊、碎浪钳 |
| **岩生类** | 土 · 忒拉蒙 | 移动慢、结阵不追、喷霜减速、把地面结晶变滑，靠"把环境变成对自己有利"——**镇守**是静止领域、硬化、不迁（00A 7.5）。玩家想：它不追你，是场地困住你，绕开结晶区别硬冲 | 盐、结晶与腺体：盐囊、晶化皮、盐柱、制冷腺、碱腺、结晶腺、盐角 |
| **翼兽类** | 风 · 埃俄隆 | 快而脆、盘旋俯冲拉升、抓的是俯冲那一下——**疾行**是"位移不算代价"、射出去还会回来（归风长弓，00A 7.6）。玩家想：它一直在动，预判那一下，别追 | 羽、翼骨、翼膜与感官器官：隼羽、翼骨、无声羽、感水腺、翼膜、双脑 |
| **旧矿坑类** | 暗 · 倪克丝 | 只在旧矿坑、怕光、镜面皮反射、墙内物可穿墙、井底物用声音引你下去——**潜隐**管潜行、禁声、痕迹抹除，努卡拉就在晦窖旧矿坑最下层（00A 7.10 / 8.1）。玩家想：看不见、抓不住、有的打不到，靠光与时间提示走 | 腔体、皮与核：石化肌腱、肺囊、镜面皮、共鸣腔、恒重核、井底泥（墙内物无掉落） |
| **遗械类** | 电 · 刻拉诺斯 | 没有恶意只有程序、固定路线巡逻不追远、主控指挥其他遗械、接触放电——**传导**管指令下达、连锁与击发，00A 7.8 特性里就写明了"遗械类怪物"。玩家想：它不是活物，掐掉主控比硬打省事 | 金属、齿轮、电节与核心部件：齿轮、拾取臂、电节、指令核心、绞盘、破岩头（载具部件）、主机核心 |
| **拟态类** | 光 · 琉明娜 | 完全静止、伪装成墙、门、NPC、水、影子、任何见过的东西——你是"看见了"，其实没照见，这是**映照**（显形、幻象）被照坏后的反面（00A 7.7）；畸息的总源头就是这一柱下界那一次。玩家想：看不等于看清，先验证再靠近 | 拟态膜、皮与核：泥壳、拟态膜、声囊、拟人皮、影囊、水拟膜、千面核 |
| **寄生类** | 木 · 薇兰蒂 | 不"吃"只"连接"、寄生血液与体液、输血藤抽血、借壳钻进别的怪物增强它——**共生**是嫁接、器官变异、活体装备、身体"一段还在长的过程"（00A 7.2）。玩家想：它跟宿主是一体，火与盐能断连接 | 腺体、藤与血囊，多作治疗材料：抗凝腺、血藤、吸附腺、拟心、血雾囊、血囊、寄壳腺 |
| **巨兽类（Boss）** | 火 · 伊格妮丝 | Boss 战全是场地级、一次性、燃尽即止：水涌只能跑、胎是一个选择、长夜的锅炉是弱点、碎晶王受击反而变强——**燃焰**是"一切以消耗换输出"，爆发最强（00A 7.4）。玩家想：Boss 不刷材料，是一场打完就没了的消耗战 | 遗物、核心与晶核，不作量产材料：门闩、遗物·雨、涌心石、溺母肺、主机核心、共鸣钟、晶核 |

**音、时间、空间、能量四柱之息不成群**，只化作四道「**神鸣**」（辉石生长、光帘、双月与兽潮、石纹脉动）——所以这四柱没有专属类群，但它们的息出现在所有类群的特殊器官里（00A 第六节，第九纪残息；第十节索引）。**这是设定，不是剧情伏笔，不引出神显圣**：当前时间线诸神缄默、不显圣、不授谕，玩家从头到尾只在打息、拆器官、凑材料，不会等到任何一柱下场。

## 十三、生态关系

```
底层：盐草、藻类（生产者）
   ↓
滩虫类、礁鱼类（食草/滤食）
   ↓
甲壳类、翼兽类、岩生类（捕食）
   ↓
巨兽类（什么都吃）

旁支：寄生类（吃血）、旧矿坑类（吃旧矿坑里的东西）、
      遗械类（吃金属）、拟态类（吃信任）
```

**这个生态的特征：它跟着矿坑的渗水上下班。**

水退 → 滩虫出来吃 → 捕食者出来吃滩虫 → 水涨 → 全部退场。

玩家（旧矿坑猎人）挤在中间：和食腐者抢东西，和捕食者抢命。

## 十五、给美术的约束

1. **一眼能归类**：滩虫小而多，甲壳慢而硬，礁鱼快而滑，旧矿坑类苍白而僵。
2. **特殊器官必须外露**：玩家要能看出打哪里。
3. **不写实**：这些东西应该看起来像"海里的东西长到了陆地上"，不是"地狱怪物"。
4. **颜色编码**：滩虫灰绿、甲壳赭红、礁鱼青蓝、盐生纯白、旧矿坑苍白、遗械铁灰。拟态类的颜色与伪装环境一致。
5. **人在画面上要小**：怪物大，玩家小，压迫感自己就出来了。
