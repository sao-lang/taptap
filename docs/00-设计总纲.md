# 00 · 设计总纲

> 《定线人》设定集 第〇册
> 这本册子回答一个问题：**我们在做一个什么游戏，以及我们绝不做什么。**

---

## 一、一句话定位

**外星球上的剑与魔法 × 工业革命 Roguelike RPG。** 竖屏单手可玩，跑图、打怪、种田、经商、下矿坑。主线 25–30 小时，长线经营玩一年。

## 二、世界观一段话

外星球**洛雷亚**，海上浮着一块大陆。地下长着会发光的**辉石**——握在手里念咒是**咒术**（代价：皮下长石纹，纹满人亡），扔进炉里烧是**机工**（代价：机器贵）。城市有路灯、工厂、铁路和机关人**傀人**；乡下有牛耕、水磨和满臂发光的咒师。**大陆干线（环大陆铁路）正在测绘，而图纸上有假。** 你是王家测绘局的学徒，主线就是查出一桩测绘造假案，最后亲手把线画对。

## 三、设计红线（不做什么）

1. **不做世界拯救者**：主角是学徒，不是勇者。终局对手是公文与账目
2. **不做种族数值悬崖**：九族属性总分恒等（11），差异来自身体而非数值
3. **不做职业通用词**：没有"弓手/法师/战士"。20 条线，每条三阶三个名字，全部从军队、行会、工厂、村落的真实位置长出来
4. **不做断代史**：历史从河谷争水连续走到铁路时代，没有失落的古代文明
5. **不做凑数设定**：每个条目必须能回答"它改变玩家做什么/怎么想"，否则删
6. **不做猎奇世界**：正常的天、正常的草（虽然是青灰色的）、正常的人情——外星感来自天文与生态细节，不来自废土与巨骸

## 五、五条核心咬合（设定之间的箭头）

1. **辉石**：同一种能源，分出咒术与机工 → 世界观的最大冲突（行会 vs 商会）贯穿主线
2. **石纹**：施咒的代价 → 咒锋线三阶、静纹师职业、静纹院剧情、纹人种族，四件事共用一条规则
3. **干线铁路**：主线（画线之争）+ 经营（运费物价）+ 载具（火车）+ 结局差异（通否），一条线串四个系统
4. **职业**：20 条线覆盖所有有名有姓的 NPC → 职业即世界观，不是玩法面板
5. **旧矿坑**：历史（百年采矿）→ 地牢（随机探索）→ 怪物（矿坑生态）→ 任务（拾遗会）四系统的同一来源

## 八、命名守则（给所有后续文档）

- **装备名**：一眼看出它是件什么东西（刀叫刀名，甲叫甲名）
- **职业名**：在这个世界的军队/行会/工厂里找得到出处
- **种族名**：像种族的自称（"某某人"式）
- **地名**：像地图上的字（河枢、铁砧城、静谷、望崖）
- **自造词**：必须在名词表里用大白话解释（01 册第八节是模板）
- **禁词**：地狱、深渊、虚空、混沌、上古、失落、神选、天命——这个世界没有这些概念
