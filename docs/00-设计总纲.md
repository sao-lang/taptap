# 00 · 设计总纲

> 《定线人》设定集 第〇册
> 这本册子回答一个问题：**我们在做一个什么游戏，以及我们绝不做什么。**
> **先读 00A（神谱与神纪）。** 十四柱是所有设定的上游，本册只是它的施工说明。

---

## 一、一句话定位

**外星球上的剑与魔法 × 工业革命 Roguelike RPG。** 竖屏单手可玩，跑图、打怪、种田、经商、下矿坑。主线 25–30 小时，长线经营玩一年。

**十四柱缄默之后的人间**——神在帘后，故事在地上。

## 二、世界观一段话

外星球**洛雷亚**，海上浮着一块大陆**瓦伦提亚**。十四位神高居**高天**，夜空那道**光帘**就是他们垂下的帘子；很久以前他们为「形先还是息先」争过一次，为「该不该下界」争过第二次，最后共同立约**缄默**：不现身、不授谕、不干预。人间只剩下五样东西是他们留下的——**血脉（十四神之裔）、裔器（三十件影子般的命名装备）、圣职（教团登记的职业）、神壤（与国界不重合的十四块地）、柱日（一年十四个停业祭日）**。地下长着会发光的**辉石**，教会说那是能量神「初纹辉晶」的余息，行会说是大地的血，商会说是矿床结晶，谁也证不了谁；握在手里念咒是**咒术**（代价：皮下长石纹，纹满人亡），扔进炉里烧是**机工**（代价：机器贵）。城市有路灯、工厂、铁路和机关人**伊格尼人**；乡下有牛耕、水磨和满臂发光的咒师。**大陆干线（环大陆铁路）正在测绘，而图纸上有假。** 你是王家测绘局的学徒，主线就是查出一桩测绘造假案，最后亲手把线画对——**全程没有神下场，对手是公文与账目**。

## 三、设计红线（不做什么）

1. **不做世界拯救者**：主角是学徒，不是勇者。终局对手是公文与账目
2. **不做种族数值悬崖**：十四裔属性总分恒等（**8**，按 A3/B2/C1/D0 实算），差异来自身体（也就是神道），不来自数值
3. **不做职业通用词，也不搬外来词**：没有"弓手/法师/战士"，也没有"地狱/深渊/虚空"式借词。20 条线全部走**三段位阶制**（侍从阶 → 誓约阶 → 冠冕阶），词根只取自本世界的神名、尊号、神器圣名与神壤（00A 第九节命名法典）
4. **不做断代史**：**神纪与人间史并行，不叠加、不换算**。人间史从河谷争水连续走到铁路时代，没有失落的古文明、没有一夜消失的帝国；神纪十一行全在旧历 0 年之前结束，凡人不知道它有多长
5. **不做神迹**（本次新增，硬红线）：神不现身、不授谕、不回应祈祷、不设神选/天命；主线、支线、结局、UI 都不出现神像、神明立绘、神圣演出。祈雨不灵，祭品只换社区与停业
6. **不做凑数设定**：每个条目必须能回答"它改变玩家做什么/怎么想"，否则删
7. **不做猎奇世界**：正常的天、正常的草（虽然是青灰色的）、正常的人情——外星感来自天文与生态细节，不来自废土与巨骸
8. **不做神像**：禁止造像。神徽只用「色点 + 一字」，刻在门楣、词条前缀与柱日牌上

> 第 5 条的例外只有一个：**神鸣**（辉石生长、光帘、双月、兽潮）是自然异象，世俗有一套解释，神纪有另一套，**剧情永不证实后者**。

## 五、六条核心咬合（设定之间的箭头）

1. **辉石**：同一种能源（初纹辉晶余息），分出咒术与机工 → 世界观的最大冲突（行会 vs 商会）贯穿主线；往上追，是神纪「形息之争」里形先/息先那笔旧账
2. **石纹**：施咒的代价 → 咒锋线三阶、驻光圣徒（原静纹师）、静纹院剧情、俄涅人种族，四件事共用一条规则
3. **干线铁路**：主线（画线之争）+ 经营（运费物价）+ 载具（火车）+ 结局差异（通否），一条线串四个系统；托帕佐斯与克罗涅斯「线画在哪 / 线画在何时」的旧账，落在听证会"证据赢了、程序输了"的僵局上
4. **职业**：20 条圣职线覆盖所有有名有姓的 NPC → 职业即圣职即世界观，不是玩法面板
5. **旧矿坑**：历史（百年采矿）→ 地牢（随机探索）→ 怪物（孽息生态）→ 任务（拾遗会）四系统的同一来源
6. **神际旧账 → 人间好感度**（本次新增）：02 册关系矩阵里 **俄涅人 ↔ 瓦尔迪恩人 -2**（俄涅瑞斯与奥瑞恩的首席对末席）、**忒拉人 ↔ 瓦尔迪恩人 +2**（忒拉蒙替奥瑞恩背了两百年死者名单）不是随机数，是高天的账在人间的影子。当地人不知道，只知道"我们家从来跟他们家不对付"

## 八、命名守则（给所有后续文档）

- **装备名**：一眼看出它是件什么东西（刀叫刀名，甲叫甲名）
- **职业名**：西方古典魔幻三段位阶。一阶**侍从阶**（Squire / Apprentice）、二阶**誓约阶**（Knight / Adept / Ranger）、三阶**冠冕阶**（Warden / Archmage / Lord / Grandmaster）。**禁止用杂役活计命名**（不写马厩徒、擦铳徒、灶下徒）；冠冕是职称，不是神选。20 个冠冕阶名固定，不许新增，全部对照见 00A 第九节
- **种族名**：像神之裔的自称（"某某人"式），且要能追到一柱神（瓦尔迪恩人=金裔、俄涅人=能量裔…）
- **神名**：通称两字，尊号取自权能或神器，**真名只刻在原初神器内侧、人间不可知**；凡间典籍里出现的"真名"一律是伪作
- **地名**：像地图上的字（河枢、铁砧城、静谷、望崖）；神壤名用「×壤」（维尔达、埃尔凯恩、鲁涅特）
- **自造词**：必须在名词表里用大白话解释（01 册第八节、00A 第十一节是模板）
- **禁词**：地狱、深渊、虚空、混沌、上古、失落、神选、天命、救世、祈祷灵验、神谕——**前四个是外来词，后七个是这个世界不存在的概念**。世界里有神，但神不选人、不下谕、不设末世

## 九、神系改造的六条接口（给后续维护者）

改动一个系统时，往这六个方向对一遍，就不会写出脱离世界观的条目：

| 接口 | 问自己 |
|---|---|
| 血脉 | 这个种族奉哪一柱？神道落在身体的哪个器官/能做不能做上？ |
| 裔器 | 这件装备承哪一柱？是 30 件裔器里的哪一类影子？ |
| 圣职 | 这条职业线登记在哪一柱？三阶名字的词根出自尊号、神器还是神壤？ |
| 神壤 | 这件事发生在哪块息壤上？它和国界重不重合？不重合才有冲突 |
| 柱日 | 这个节日/停业/供物挂在哪一柱？换到的是实际玩法资源，不是保佑 |
| 缄默律 | 有没有任何一个字暗示神显圣、神谕、神选？有就删 |

**一句话检查**：把「神」字全部遮掉，设定还成立、玩法还跑得通，才算合格——因为玩家一辈子见不到神，他们只见到血、器、职、地、节。
