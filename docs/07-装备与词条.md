## 九、生成规则

```
最终伤害 = 武器基础 × (1+强化×0.06) × (1+属性) × (1+词条) × (1 - 防御/(防御+80))
```

### 掉落生成

1. 按区域等级查品质表
2. 按怪物类型查基底表
3. 按品质定词条数
4. 逐条抽样：权重 → 排除互斥 → 排除不适配 → 定阶
5. 按"时节/月份"追加专属后缀（30% 概率）
6. 决定打孔
7. 命名

### 命名

- 0 词条：`折川刀`
- 1 词条：`裂甲 折川刀`
- 2 词条：`裂甲·晶蚀 折川刀`
- 3 词条：`裂甲·晶蚀·逐风 折川刀`
- 有特效：末尾加 `（连山）`
- 有时节后缀：加 `·月明`

**手机上最多显示三个词条。**

### 必须跑的测试

1. 10 万次生成，词条出现率在权重 ±15% 内
2. 检查"无敌组合"（千刃Ⅲ + 连山 + 破晓）
3. 验证同律Ⅲ（11%×4 件 = +44%）
4. 验证"·月明 Ⅲ"在旧矿坑里是否过强
