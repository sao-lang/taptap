## 二、武器（20 类）

### 2.0 武器按侧重方向限定

武器"定形神"是神道在器物上长出的形状（见三·补）。本册在此落实 00A 3.3.3 两条跨系统硬规则：魔道武器限定、水/时间二柱不授兵器。

**侧重方向 → 可用武器类**（数据取自 00A 3.3.2「专用武器」列）：

| 侧重方向 | 可用武器类 |
|---|---|
| 赋形 | 魔法书(造物图谱) / 通用 |
| 铁躯 | 刀 / 剑 / 斧 / 锤 / 巨剑 / 巨斧(金) |
| 异化 | 爪(木) / 弓(风) |
| 骑驭 | 弓 / 链锤 / 投掷(风) |
| 形变 | 水不授兵器，仅面罩 / 涉水甲 |
| 磐石 | 锤 / 战戟 / 盾(土) |
| 重铠 | 巨斧 / 破城锤 / 炉器(火·热武) |
| 咒术 | 法杖 / 魔法书 / 触媒 / 晶刃(魔道四专) |
| 星行 | 长枪 / 折界星盘(空间) |
| 显影 | 晶刃 / 触媒(光术) |
| 传导 | 铳 / 弩(电·金) |
| 契约 | 鞭 / 触媒(音) |
| 潜行 | 匕首(暗) |
| 辰序 | 时间不授兵器，仅面具 / 时节后缀 |

**两条硬规则（00A 3.3.3 原文）**：

1. **魔道武器限定**：凡走「咒术」「显影」两条术道的角色，**只能装备 法杖 / 魔法书 / 触媒 / 晶刃** 四类武器；其余十二个方向不可装备这四类（强行装备则法术槽不可用、对应词条不触发）。
2. **水、时间二柱不授兵器**：其上裔（涅瑞德人、艾欧恩人）无近战武器类，只有塑甲 / 面具 / 时节后缀——既有定形神设定在此被纳入方向规则统一解释。

> 强行越界装备时：法术槽不可用、对应词条不触发。玩家选族即定武器池——见 00A 3.3「一族一向」。

> 「生效方向」为更易触发的方向提示，非硬性锁死：在该方向装备上更易触发，其余方向仍可触发但收益/概率偏低。

## 九、生成规则

```
最终伤害 = 武器基础 × (1+强化×0.06) × (1+属性) × (1+词条) × (1 - 防御/(防御+80))
```

### 掉落生成

1. 按区域等级查品质表
2. 按怪物类型查基底表
3. 按品质定词条数
4. 逐条抽样：权重 → 排除互斥 → 排除不适配 → 定阶
5. 按"时节/月份"追加专属后缀（30% 概率）
6. 决定打孔
7. 命名

### 命名

- 0 词条：`折川刀`
- 1 词条：`裂甲 折川刀`
- 2 词条：`裂甲·晶蚀 折川刀`
- 3 词条：`裂甲·晶蚀·逐风 折川刀`
- 有特效：末尾加 `（连山）`
- 有时节后缀：加 `·月明`

**手机上最多显示三个词条。**

### 必须跑的测试

1. 10 万次生成，词条出现率在权重 ±15% 内
2. 检查"无敌组合"（千刃Ⅲ + 连山 + 破晓）
3. 验证同律Ⅲ（11%×4 件 = +44%）
4. 验证"·月明 Ⅲ"在旧矿坑里是否过强
